# 项目现状

本页只写当前事实，不记经过；历史见 Git。

## 当前阶段：工程整改

暂停功能开发，只修用户反馈的线上缺陷和学校上游变化；整改不新增用户可见功能。整改期间可推送 `dev`，每次发版前经维护者同意后合入 `main`。

达到以下四项后结束整改：

- **`dev` 随时可发版**：夜间完整验收连续通过 7 次，期间的失败在当天修复。
- **日常反馈在分钟级**：在同一台机器上预热增量缓存后，各测一次代表性改动；只改一个 Dart 包时 L1 少于 5 分钟，只改一个 Rust crate 时少于 10 分钟。
- **仓库信息准确、入口精简**：核对已知的过时内容均已修正，旧入口指向新的权威页，且 `AGENTS.md` 每条规则都说明防止的问题。
- **新人能接手**：从干净检出按文档安装工具、跑通 L1、用脱敏 Fixture 修一个解析问题并让 PR 通过 CI；实际走一遍并计时，修掉卡点。

## 已知问题

- 本机 macOS 原生集成用例可能卡在将 App 切到前台的步骤。
- HarmonyOS 待上架 AppGallery，签名包实机验收待补；各平台的正式包覆盖升级验证尚不齐全。
- 研究生考试详情暂不支持；健康云体测的生产 Core 双路线验证仍待完成。
- 刷新期间打开“数据与同步”面板可能看到旧状态，需重新打开；窄屏的刷新指示可能提前结束，手机启动和刷新仍可能闪动。
