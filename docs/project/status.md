## 功能与平台

| 功能/平台 | 状态 | 说明 |
|---|---|---|
| 登录与会话 | 已实现 | 支持直连、WebVPN 和自动选路，校外会话恢复已有 Android 实机验证。 |
| 教务与校园服务 | 已实现 | 支持本科课表、考试和成绩，研究生课表、成绩及考试学期，以及作业、空教室、博雅、每日课程、图书馆、场馆、评教和门户等服务。路线与操作的验证范围见[协议依据](../protocol/README.md)。 |
| 财务收入 | 已实现 | 支持查询和离线查看财务收入，详情显示部门名称、项目编号和项目名称。 |
| 图书馆当前借阅与续借 | 已实现 | 从「我的 → 待还图书」进入，支持单本续借和原路线核对。Direct 会话复用和列表读取已有脱敏 HTTP 证据。生产 App 双路线读取、真实续借与设备验收待补。 |
| 日程 | 已实现 | 支持本地编辑、导出 `.ics`、导入当前学期课表，以及经北航云盘同步。云盘同步默认关闭，已通过直连验证，WebVPN 待验证。 |
| 北航云盘与图书馆云打印 | 已实现 | 提供云盘文件管理和云打印、扫描相关功能；部分 WebVPN 链路和系统文件面板待验。 |
| 应用服务 | 已部署 | 提供更新检查、公告和经同意的使用统计。 |
| Android、iOS、HarmonyOS | 已实现 | Android 有签名 APK 和实机运行记录；iOS 有签名 IPA 和模拟器构建记录，课表组件需 iOS 17 及以上；HarmonyOS 有无签名 HAP 和模拟器合成验证记录。 |
| Windows、macOS、Linux | 已实现 | 图形界面与命令模式共享账号和本机数据；Windows 与 macOS 有本机联调记录，Linux 已验证隔离容器内的 SSH 无界面模式。 |

## 已知问题

- 本机 macOS 原生集成用例可能卡在将 App 切到前台的步骤。
- 交付产物已改写到 `dist/`、CI 临时签名材料改放 `$RUNNER_TEMP`，发布工作流尚未在新路径下实际运行，下次发版时留意。
- HarmonyOS 待上架 AppGallery，签名包实机验收待补；各平台的正式包覆盖升级验证尚不齐全。
- 研究生考试详情暂不支持；健康云体测的生产 Core 双路线验证仍待完成。
- 刷新期间打开“数据与同步”面板可能看到旧状态，需重新打开；窄屏的刷新指示可能提前结束，手机启动和刷新仍可能闪动。
