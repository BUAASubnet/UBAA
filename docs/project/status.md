共享会话重绑会先撤销旧的本机提示读取，重绑完成后重新加载，避免旧任务把正常会话更新报告为操作冲突。上述 GUI 恢复调整已通过合成回归，当前版本的真实账号和设备验证尚未执行。

登录错误已通过 Bridge 保留固定阶段和原因，本地诊断分别记录失败路线，并支持从错误卡复制关联记录、应用版本和平台。通用响应异常使用中性提示，遥测与 CLI JSON 协议保持原样。确定性回归覆盖原因传递、路线选择与安全复制，设备端待验收。

云打印错误已保留 Core 实际路线，包括 Auto 回退后的 WebVPN 和上传、删除的逐项结果。选路前的本地参数错误不附带路线。Direct/WebVPN、回退及写入不重放已有合成回归，真实云打印路线验收范围仍见上表。

换网恢复已接入独立网络探测、3 秒观察缓存、Rust 只读取消和 30 秒统一期限，保留页面及原查询。校外名单外的初始 Direct 连接预算为 2 秒，正常响应预算不变；手动切换不再额外读取两条登录页。合成回归覆盖连续换网、原查询重读、迟到结果拒绝、写入不重放和超时后的手动重试。macOS 原生插件、FFI 和合成恢复的 6 个入口、13 项测试已通过，真实校园网到移动网络切换仍待验证。

Auto 校外按[域名名单](../contracts/route-policy.md#校外域名配置)直接为用户中心、希冀、课堂签到、iHome 和财务选择 WebVPN，名单外业务继续直连优先。2026-11-13 已在非校园网环境检查公开入口与 DNS，并通过 Core 路线合成回归；财务按用户确认采用 WebVPN，PR #124 已有真实 WebVPN 查询证据。本次没有执行账号登录、完整业务读取或设备换网验收。

应用操作占用和会话恢复结果已集中管理，专用服务恢复继续阻塞并发操作。日程同步的未决发布状态、希冀扫描的网络读取与缓存复用也由专用类型管理，公开接口与本机存储格式保持兼容，见[内部状态所有权](../adr/0008-internal-state-ownership.md)。

恢复本机首页会保留同账号的记住密码和自动登录选项，同账号重新认证继续沿用原选择。自动恢复遇到上游解析异常时，只暂停当前运行中的自动提交，保留已保存凭据与下次启动的恢复许可。两项行为已通过合成重启回归，真实设备与学校账号尚未验证。

Core-live 的全部功能已统一使用固定路线的 `UbaaClient`，登录复用客户端静默认证及自动验证码流程，财务不再采用独立登录分支。Direct/WebVPN 的合成请求回归覆盖普通登录、验证码成功与耗尽、服务异常和账号不匹配；已完成希冀 Direct/WebVPN 登录成功样本及两条路线的 96 份作业完整 DTO 读取。2026-11-13 WebVPN 独立新会话自动验证码登录补验成功；历史 `upstream_changed` 仅有错误码，未能确定具体原因。

首页刷新将课表与考试分到独立读取队列，全局最多八项在途。展示日期课表与补充来源并行等待，同一刷新代次只读取一次；希冀已有详情或已确认空缓存时先交付首页，列表核验和过期详情复查在后台继续，学校日程刷新仍等待完整结果。本地合成测试已覆盖并行请求、日期读取去重、缓存先展示和失败保旧。2026-11-14 macOS Debug 原生首页真实验证：Direct 空业务缓存前台加载 4.40 秒，两次缓存刷新 2.26/2.61 秒；WebVPN 分别为 8.40 秒和 6.26/2.46 秒，全部首页来源读取及保存成功。前台最后等待考试，后台继续补全希冀和整学期课表；手机 Release 耗时待测。见[首页刷新来源对照](../protocol/parity/home.md#首页刷新等待与教务并发2026-11-14)。

希冀自动读取复用五分钟有效目录和活跃课程索引，手动刷新重新发现作业，全量刷新及当前详情保留强制读取。本轮网络索引带有唯一明确选中作业时复用完整正文。两条路线在同课程内共用父会话，至少两份详情需要读取时采用最多四并发，认证恢复和课程切换保持串行；跨课程批量任务保留独立 worker。无持久存储时继续使用内存缓存，连续缓存详情最多十六份合并发布。2026-11-13 同入口样本中，WebVPN 全量读取从 13.28 秒降至 10.26 秒；Direct 请求数从 177 降至 117，但耗时波动较大，尚不能确认稳定提速。两条路线完整 DTO 均通过对照，详见[来源与验证范围](../protocol/parity/coursework.md#同课程详情预取与索引正文复用2026-11-13)。

## 已知问题

- macOS 原生集成测试有一次日程编辑断言失败，没能复现，原因不明（2026-11-11）。
- 刷新期间打开“数据与同步”面板，面板可能继续显示刷新前的旧状态，需要重新打开。
- 窄屏下的刷新指示可能比实际刷新提前结束。
- 手机启动和刷新时有闪动，是否由客户端重建引起，还需要运行记录确认。
- 两个历史未知项：原生合成退出测试曾进入生产 SSO 退出路径，无法确认请求是否到达学校；命令开发中一次参数校验超时，对默认本机材料的影响无法确认。参数前置校验已修复，这两项不再重放。

自动化测试覆盖不到的场景（原生登录到查询的完整流程、软键盘、真实账号的恢复与性能等）见[测试策略](../development/testing.md)。
