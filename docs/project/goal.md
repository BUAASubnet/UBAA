完整实施顺序、代码位置、失败反例和完成条件见[应用服务实施计划](../design/app-service-implementation.md)。产品行为以[应用服务合同](../contracts/app-service.md)和 [ADR 0008](../adr/0008-app-service-worker.md)为准。

本任务交付 Rust Core 共享状态和独立通信、TypeScript Worker 与 D1/KV、GUI 与命令模式接线、隐私政策和设置入口、更新门控与公告、统计汇总和清理、自动检查及部署发布工具。

## 执行方式

按同一个完整功能任务连续完成实现、接线、测试、修复、复审、文档和本地提交。步骤完成后继续下一步，不以等待阶段确认结束执行。常规实现选择按现有代码和合同自行决定。外部条件缺失时继续独立工作，保留具体未验证项和恢复条件。

工程完成要求合同全部行为已实现、规定的确定性检查和本地端到端验收通过、提交可审查。生产部署、商店上架及目标设备验收分别记录，不能用本地通过代替。部署、推送、发布和真实学校操作仍遵守当前执行会话的授权及 [AGENTS.md](../../AGENTS.md)，本计划不提供额外授权。

实际结果写入[迁移状态](status.md)，验证命令以[开发命令](../development/commands.md)为唯一入口。此前日程同步和产品验收的事实继续保存在状态页，本任务不恢复其他工作树中的未完成工作。
