# UBAA 文档

按你的用途查找使用指南、开发资料或维护手册。

## 用户

- 从官网浏览使用指南和公告。[文档站](https://www.ubaa.top)
- 查阅用户指南、公告和下载页的仓库文件。[站点源码](site/)
- 选择适合设备的安装包。[下载安装](https://www.ubaa.top/download)
- 安装应用并完成首次登录。[开始使用](https://www.ubaa.top/guide/start)
- 从旧版升级前查看变化和迁移说明。[新版变化](https://www.ubaa.top/guide/ubaa2)
- 查阅校园功能和桌面命令模式的用法。[功能总览](https://www.ubaa.top/features/)
- 排查登录、连接或安装问题。[常见问题](https://www.ubaa.top/tech/troubleshooting)
- 了解数据用途、保存方式和删除渠道。[隐私政策](https://www.ubaa.top/tech/privacy-policy)

## 贡献者

- 从克隆仓库开始，在本机运行 App。[快速上手](development/getting-started.md)
- 了解反馈、日常开发和提交 PR 的要求。[贡献指南](../CONTRIBUTING.md)
- 按改动选择准备、检查和测试命令。[开发命令](development/commands.md)
- 查阅分支、提交、文档和日志的约定。[开发约定](development/conventions.md)
- 了解分层和请求流转，并定位代码。[架构概览](architecture/overview.md)
- 查阅日程、云盘和命令模式的设计。[产品设计](design/)
- 查阅导航、响应式布局和操作反馈的规格。[Flutter UI 规格](design/flutter-ui-spec.md)
- 查阅功能、平台及验证现状。[项目现状](project/status.md)

## 维护者

- 按功能查阅上游证据、协议差异和决策记录。[协议依据](protocol/README.md)
- 查阅认证、会话、缓存、Bridge 和应用服务的行为约定。[合同](contracts/)
- 按平台构建、验收和分发安装包。[客户端发布](runbooks/flutter-release.md)
- 核对各平台的签名身份、配置与验收步骤。[应用签名](runbooks/app-signing.md)
- 部署应用服务并维护渠道、公告和数据库。[应用服务部署](runbooks/app-service.md)
- 编辑、预览、部署和排查用户网站。[文档站手册](runbooks/docs-site.md)
- 按授权验证直连与 WebVPN 的真实只读操作。[真实只读验证](runbooks/live-readonly-verification.md)
- 收集并检查脱敏诊断报告。[本地诊断](runbooks/local-diagnostics.md)
