# 决策记录

这里只记录仍影响维护判断的决定。逐操作来源和真实观察见[协议对照](README.md)，长期架构见 [ADR](../adr/)，被替代的方案和实施过程查 Git。

## 2026-11-21：恢复隐私政策明示同意

图形宿主在接受当前政策后才继续登录或恢复，拒绝保持账号材料；接受前只可重试已有删除标记。依据是应用市场审核反馈和已经提出的删除请求需要继续处理。应用服务共享同意与宿主记录分开，命令不增加交互；见[同意规则](../contracts/app-service.md#3-同意与开关)和[来源对照](parity/app-service.md#恢复明示同意2026-11-21)。

## 2026-11-19：希冀 WebVPN 批量入口复用业务激活，评估后不采用

不为独立批量入口扩大跨课程激活复用。首页渐进读取已在计划内复用，双路线只读对照的性能差异落在波动范围；主要成本是选课、索引与逐份详情请求。希冀优化优先复用持久详情、跳过已确认的往期范围；有新证据再评估批量入口。

## 2026-11-19：区分撤销令牌和内容版本

业务会话旁车用路线撤销令牌隔离清理前后的任务，用内容版本通知其他进程重载；主会话修订无法区分常规刷新与材料撤销。撤销由拥有权属的失效路径在源头完成，冲突方只撤掉本机种子。新主会话发布前在主会话锁内尝试撤销，注销先写墓碑、远端尽力注销后按原权属清槽。锁顺序为主会话、旁车；撤销失败不阻塞登录或退出，但本进程暂停旁车直至补完所有待撤销路线。适用于普通和固定路线客户端，细节见[会话合同](../contracts/connection-and-session.md#业务会话缓存)。

## 2026-11-18：业务令牌进入业务会话缓存

仅允许保存经核实账号和路线下的 Byxt/Portal Cookie、学生身份、SPOC 与阳光打卡业务材料。固定 buaa-api 的 SPOC 时效可作依据，阳光打卡的保留期仅是本机复用限额；记录页被拒只淘汰匹配材料，不扩展概览的一次重登。签到和博雅缺少等价的失效与有界恢复依据，继续只用内存。旁车不授予写资格，任何诊断导出均不收集旁车文件。见[准入对照](parity/auth-session.md#学生身份与业务令牌准入)。

## 2026-11-17：chrono 与 chrono-tz 停止维护公告暂登记豁免

只豁免 [`deny.toml`](../../deny.toml) 中对应的两条停止维护公告。两库是日程重复规则和校园时间的基础依赖，公告不是已知漏洞，不能以局部升版解决。迁移时同时评估重复规则库；漏洞或其他公告仍由门禁阻断。

## 2026-11-17：博雅时间判定固定按东八区

将无时区的博雅时间按北京时间解释。旧服务端的本地时区与校园时间一致，设备时区没有该保证。适用于课程状态、签到签退、退选和选课时间，以及界面跨时间边界重读；写资格仍只由新鲜在线结果授予。

## 2026-11-17：会话活动时间每 60 秒至多单独落盘一次

仅活动时间变化时节流持久写入，内存仍记录本次成功核验。连续读取和命令启动无需每次改文件；旧服务端的合并时长不构成空闲 TTL。适用于主会话的活动时间，不延迟 Cookie 更新或失效，不改变 Cookie 有效期，也不授予派生读组写会话权限。

## 2026-11-17 主动分享完整诊断

完整诊断保留原始学校响应供用户主动分享，导出前说明可能含个人数据或凭据。原始正文有助于定位解析与协议问题，采集由 Bridge 显式装配且仅用有界内存。普通预览、复制、日志及自动遥测继续只使用安全字段；完整报告不自动上传，不改变请求控制流。见[本地诊断手册](../runbooks/local-diagnostics.md)。

## 2026-11-17 共享资料目录的同查询读取恢复

同账号同查询的跨进程竞争只复用同世代的较新完整结果；已取得完整数据最多再领一次本地发布票据。GUI 与命令共用目录，读票冲突不代表学校请求失败；部分结果不为此重发。退出、换号、清理、业务写入失效及同实例替代继续撤销旧发布；无较新修订或同世代证据时保持失效。见[离线缓存合同](../contracts/offline-cache-and-recovery.md)。

## 2026-11-16 错误诊断的来源与传递

诊断随原错误保留安全来源、阶段与原因，不改变公开错误码或请求控制流。未知上游文本可能含个人数据，仅截断不足以安全共享；自动报告只发送按协议证据确认的允许内容。计数与错误详情分开保存，详情遵守同一同意、删除及保留期限；完整报告走独立的主动分享入口。

## 2026-11-12：博雅列表保留服务端顺序

选课列表按服务端顺序续载，搜索筛选保留相对次序，刷新采用服务端最新顺序。客户端按开课时间全量重排会让后页插入当前首屏。适用于 App 列表，不改 Core 查询及分页；见[来源对照](parity/bykc.md#博雅列表展示顺序2026-11-12)。

## 2026-11-11：博雅按需分页与稳定刷新

接近列表末尾才续载，刷新保留已加载范围，全部到齐后统一替换。固定预取会增加用户未滚动时的请求，逐页替换会破坏当前位置。只读内容继续显示，旧动作撤销；失败保留旧列表以便重试。具体范围以[博雅对照](parity/bykc.md#博雅列表缓存与按需分页2026-11-11)和[当前缓存合同](../contracts/offline-cache-and-recovery.md)为准。

## 2026-11-11：博雅退选截止时间

已选且未开课时，还须未超过学校退选截止；恰好等于截止允许，缺字段沿用开课规则，存在但无法解析时资格未知。两份冻结 DTO 都提供截止，但旧流程未校验；维护者要求在列表、详情、准备和提交前使用同一限制。见[逐操作对照](parity/bykc.md#博雅退选截止时间2026-11-11)。

## 2026-11-11：统一本地环境配置与应用服务 CD

本机环境以根目录私有配置为来源，由各入口的白名单控制可读范围；普通工具不能取得学校账号或部署凭据。统一配置减少重复维护，不以合并文件扩大授权。应用部署和内容发布分别遵循[现行部署手册](../runbooks/app-service.md)的分支和保护规则，不能从普通检查入口触发。

## 2026-11-10：应用服务的学号派生标识与数据出境

维护者要求跨设备去重和统计年级，因此仅允许[应用服务合同](../contracts/app-service.md#7-用户派生标识与年级)定义的派生标识经遥测出口上传。客户端派生值仍可能被枚举，不作匿名数据处理；学号和派生值均不得进入日志、诊断报告、测试证据或提交。部署与数据地点以[当前部署手册](../runbooks/app-service.md)和[隐私政策](../site/tech/privacy-policy.md)为准。更换部署地点须重新核对数据流与披露；本决定只授权遥测例外。

## 2026-11-10：同账号内容与请求生命周期分离

按已核实的本机账号保存页面内容，网络代次只撤掉旧读取和动作。展示资料可能从遮罩更新为在线完整值，不能用来识别切号。补登录或重建保留导航、分页和草稿，完整新结果再替换；退出、换号、改变路线范围或清缓存时仍清掉对应内容。见[缓存合同](../contracts/offline-cache-and-recovery.md#同账号资料的连续展示)。

## 2026-11-09：CI 依赖审计

对当前无法合并的依赖重复项和不可替代的停止维护公告，只按 [`deny.toml`](../../deny.toml) 的明确范围豁免。这样可以继续使用依赖方发布版而不派生私有分支；当上游可合并或替换时删去例外。已修漏洞与旧依赖版本由锁文件和 Git 记录，不成为豁免依据。

## 2026-11-09：研究生当前学期采用学校标志

默认使用 GSMIS 唯一的当前学期标志，并与目标接口的候选列表匹配。下一学期可提前开放，倒序、月份和可查周位图都不可靠。考试和课表各保留独立候选，显式历史查询不依赖当前学期。见[来源对照](parity/gsmis.md)。

## 2026-11-08：门户身份统一分流学业系统

课表、考试和成绩统一使用在线门户身份而非学号形状选择本科或 GSMIS。门户明示身份可覆盖编码例外；未知身份按不支持处理，门户失败时不探测另一学籍系统。身份复用限制在同一路线及认证代次。见[学业来源对照](parity/academic.md)。

## 2026-11-08：研究生排课缺失方案编号

缺少编号时仅从唯一可用作息方案补全。公开问题记录出现空编号和唯一方案；多候选或已给编号不匹配时不能猜测。适用于 GSMIS 课表解析，见[公开记录与来源复核](parity/gsmis.md)。

## 2026-11-08：紧凑侧栏在矮窗口直接显示全部分组

紧凑侧栏在纵向不足时让全部分组保持可达，并允许内容滚动。仅用空间不足来隐藏分组会使功能入口难以发现；适用于矮窗口，不改变导航结构或功能可用性。

## 2026-11-08：HTML 正文纯文本保留分段并完整解码实体

纯文本投影保留有意义的换行和段落，使用 HTML 解析器完整解码实体。直接合并文本节点会吞掉段落，局部手写替换会遗漏实体。适用于已有学校正文和说明的纯文本展示，不渲染上游 HTML，不对已解码文本重复解码。

## 2026-11-07：首页主会话与单项目标恢复

主会话就绪后，单功能恢复只更新对应读取，不阻断其他首页来源，也不推进共享账号代次。功能路线不足不代表主账号失效；真实重登或外部换号仍撤销旧计划。首页批次只能复用同实际路线、同认证代次和同配置的核验，仍逐操作检查持久身份。适用于首页读取和待办投影。

## 2026-11-06：SSO 直接验票与域名路线缓存

主会话以 SSO 直接验票为准，UC 只负责资料。校外 UC 不通时真实验票仍取得身份，跳转、Cookie 和输入账号不能代替核验。Auto 的同域名读取回退与时限偏好见[路由合同](../contracts/route-policy.md)，其证据不授予写回退或跨路线复制认证材料。见[认证对照](parity/auth-session.md#sso-身份核验与-uc-解耦)。

## 2026-11-06：SSO 图像验证码按当前准备状态直接提交

沿浏览器行为直接提交当前准备页的挑战，不在提交前重取登录页。真实观察显示再次 GET 会更新 execution 和验证码标识。拒绝后只使用响应中有效的新挑战，在有界静默尝试后交人工；统一拒绝文案不单独作为删除凭据的依据。适用于路线内的图像验证码，且仍校验账号、代次、有效期与取消状态。见[认证对照](parity/auth-session.md)。

## 2026-11-05：希冀作业详情使用独立正文预算

仅给精确的希冀详情 GET 更大的解压后正文预算；真实结构中的长代码需要完整 HTML，通用放大预算会扩大其他接口的内存占用。授权目标、网络路线和流式对象下载不受影响。见[正文预算对照](parity/coursework.md#希冀作业详情正文预算)。

## 2026-11-05：北航云盘的认证与分享关联

OAuth 使用冻结旧版的 service 编码、challenge 解析和 SSO GET 会话，不复制 buaa-api 的第二份表单登录。分享更新必须使用创建或历史结果中有明确依据的完整对象关联；单项 record 缺关联只可查看或取消。适用范围、定位和未验证分支见[云盘对照](parity/bhpan.md)。

## 2026-11-05：统一 App 命令入口与材料共享

公共 Rust 库统一命令定义和输出，由 Dart 复用 GUI 的账号、恢复及写确认。平台分流只改变运行时，不新建身份库。macOS 使用无窗口 Engine 并关闭沙箱以访问用户指定路径；旧容器和非容器资料同时存在时停止，不擅自复制或合并。Linux 命令使用无图形 AOT 与同一 Secret Service，锁定或需提示时失败，不改用明文。见[命令设计](../design/app-command-mode.md)。

## 2026-11-05：北航云盘的动态传输授权

Direct 对象传输使用同操作当次授权给出的 HTTPS 目标及请求头；两份来源都动态提供这些值，没有固定对象主机表。标准 GET 只作为下载地址的最小消费方式，不据此增加 Cookie、Range 或续传。此例外不扩大认证跳转白名单，不接受宿主地址、历史授权、对象重定向或额外认证；详见[云盘对照](parity/bhpan.md)。

## 2026-11-05：日程同步的版本比较与本机快照

按记录修改时间、设备标识和持久序号合并；同版本不同正文拒绝，确认逐条核对原内容和版本，保留发送期间的新编辑。设备发布顺序不是记录冲突顺序，远端回执也不能证明本机未修改。适用于 GUI 和命令共用的账号库；云端文件身份另见不可变快照决定。

## 2026-11-05：OHOS 下载文件交付

系统文件选择只提供一次性目标；应用对本机文档路径独占创建，拒绝远端 URI 和已存在目标。ArkTS 的打开方式没有等价的独占创建保证，因此由 Dart 执行逐块交付，并在关闭句柄后只清理本次残留。适用于云盘保存，不扩大外部文件提供方支持范围。

## 2026-11-05：日程采用设备独立的不可变快照

每设备以持久序号新建快照，不原子覆盖共享文件。Direct 实测同一基版的两次并发登记均成功，不能以版本字段证明至多一方提交。明确成功回执加固定对象及完整正文读回才确认；未知保留原身份，不换名重发。本机清除不删云端，可能已发送的发布继续占在途位置。适用于[日程同步](../contracts/agenda.md#跨设备同步)，不否定云盘单独的版本读取能力。

## 2026-11-02：共享身份撤销与本进程句柄关闭

Core 只接收平台事务捕获的身份目录与代次，不读取宿主安全索引或密码。材料共享锁保护本地提交，身份变化用独占锁；网络等待不持锁，交付时再校验。普通关闭只释放本进程资源；显式全局退出使用受限清理票据，不能转换为普通权限。这样多个消费者可以共享资料而不相互登出，也避免身份撤销后接收旧结果。见[共享资料设计](../design/desktop-shared-state.md)。

## 2026-11-01：日程关闭先收束已交付写入

Dart 日程服务先撤销旧访问，再等已交付的持久写入收尾，下一次打开不得越过关闭。同账号重开会重新激活库，仅靠持久 active 标记挡不住旧队列。适用于增删改、完成、覆盖和显式清除；读取不阻塞关闭，`superseded` 不证明未提交。见[日程对照](parity/agenda.md)。

冻结旧版 `1f4b8f8412272b6a423d4ad92b396e3db721e6f3` 的 `HomeTodo.kt`、`LocalScheduleApi.kt`、`CredentialStore.kt` 和 buaa-api `a63712fa2ae0a6c8066197063ddee98e3a6b5b81` 的 `src/api/cloud/{mod,core,opt,data}.rs`、`src/request.rs`、`src/store/cookies.rs` 均无等价本机日程事务。上游操作列不适用；本机 DTO 沿原日程类型，并发与错误语义按上述关闭顺序。

## 2026-11-01：首页复用已取得结果进行 Core 投影

首页将已取得的 typed 结果交给纯 Core 投影，再叠加同账号覆盖。持久缓存可能缺失或保存失败，不能取代成功在线结果；投影既不重读学校也不伪造取得时间。签到只继承当次唯一有效在线动作，覆盖和缓存均不能创建资格。见[首页对照](parity/home.md)。

## 2026-11-01：日程范围快照与 iCalendar 依赖

按 RFC 5545 导出发生项的范围快照，使用锁定的 `icalendar` 构建组件，用本地线性写入器完成长 UTF-8 折行和转义。冻结来源没有等价导出，通用折行在长文本中有二次成本；输出整体受预算约束。适用于范围导出，不承诺可编辑系列的往返同步。见[导出合同](../contracts/agenda.md#rfc-5545-范围快照导出)。

## 2026-11-01：H2 命令骨架、平台分发与停止规则

停止预算从原生入口单调时钟起算，输入、恢复、执行与有界收尾共用约定。只读首次明确认证过期且归属、路线和许可仍有效时可完整重跑一次；准备或提交后不自动重做写入。输入快照检查不能被平台 stdin 绕过，短写和 flush 失败应报告。各平台分发、停止映射及性能目标见[命令设计](../design/app-command-mode.md)；Mock 不作为原生进程证据。

## 2026-10-31：缓存预读与博雅首屏分页

## 不记住密码时使用本次会话

恢复许可只控制重启与其他进程；显式登录可按原账号代次使用本次已核实会话，不读取保存凭据或采用继任快照。这样既不阻断本次登录，也不扩大自动恢复许可。会话失效后转人工登录；不保留登录的读组仅在内存更新业务材料。主会话仍按双路线持久合同保存，改变为纯内存需先解决跨进程条件替换，不能从开关名称推断已经实现。
