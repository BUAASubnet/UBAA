# 北航云盘边界合同

## 概念

GUI、App 命令和日程同步复用 Core 的云盘认证、目录、分享、文件管理与传输能力。Core 持有协议和授权；宿主管理确认、进度及本机文件选择与交付。未取得来源依据的全文检索、在线编辑、文件版本管理、预览和持久断点续传不作为可用能力。逐操作依据见[云盘对照](../protocol/parity/bhpan.md)。

### 当前 typed 入口

签名、DTO 和版本能力以 [云盘 facade](../../crates/ubaa_core/src/facade/bhpan/)、[云盘领域类型](../../crates/ubaa_core/src/domain/bhpan/)、[Bridge API](../../crates/ubaa_flutter_bridge/src/api/bhpan/)和[命令定义](../../crates/ubaa_command/src/command/bhpan.rs)为准。

## 不变量

- **作用域独立。** 个人授权绑定当前账号和实际路线；分享授权绑定特定分享及后代对象，不能回退为个人 Token。分享另存分别核对源分享和目的目录授权，下载批次不混用授权。分享密码留在 Core，只有用户明确请求的分享链接进入专用功能输出。
- **句柄与路线绑定。** 对象、确认及传输由 Core 以不透明句柄绑定客户端、账号、实际路线、会话和用途。身份、路线或生命周期变化后，未发送阶段停止，迟到结果不进入新状态。只开放已有证据的 Direct 能力；WebVPN 未验证，不将网页回退用于文件和对象传输。
- **只用当次传输授权。** 动态 HTTPS 地址、对象存储头来自同一操作的当次响应，由 Core 校验并消费。对象传输隔离学校 Cookie、个人和分享 Bearer，不接受宿主任意地址、不跟重定向，也不补入额外认证。签名 URL 和请求头不进入普通输出、诊断或缓存。
- **读取范围不可扩大。** 目录和回收站等列表只有证明范围及结束才能声称完整。部分列表不能证明对象不存在，不能驱动全部删除、全量替换或完整同步；展示路径、旧列表、建议名称和缓存均不锁定目标。覆盖现有对象须有明确授权和版本条件，不能把版本参数当作已验证的原子条件替换。
- **单次确认、分阶段发送。** 写入绑定当前目标与实际路线；每个可能产生效果的阶段至多发送一次。对象传输、分块合并与最终登记分别确认，已传字节或可下载的暂存内容不证明已登记。批次逐项交付，出现未知后停止后续写。永久删除、移入回收站和取消分享分别确认。取消只能停止尚未发送的阶段，不能承诺远端回滚。
- **本机交付。** 只缓存允许的元数据，不保存授权、写资格或传输正文；缓存不授予操作权限。文件目的地由用户明确选择，既有同名文件不被隐式覆盖；失败只清理由本次创建的残留，清理失败向用户说明。

## 错误语义

- 认证不足与分享过期使用各自恢复入口。权限拒绝、同名冲突、目标变化、范围不完整、协议变化和本机文件故障分别呈现，不以普通空列表或直接重新提交掩盖。
- 区分发送前拒绝、确定业务拒绝、确定成功与 `outcome_unknown`。可能已发送但无法证明结果时不自动重发，只在原授权、原路线及原目标上读取核对；同名文件或某阶段成功均不足以确认。部分失败不改写已经确认的结果。
