# 日程 Core 合同

## 概念

Core 管理本机事项、重复展开、学校事项投影、本机覆盖、范围导出和云盘同步。GUI 与 App 命令共用账号日程服务，通过 [Core facade](../../crates/ubaa_core/src/facade/agenda/) 和 [typed Bridge](../../crates/ubaa_flutter_bridge/src/api/agenda/) 访问。数据与操作以 [Core 日程模型和存储](../../crates/ubaa_core/src/agenda/)、[Dart 日程服务](../../packages/ubaa_domain/lib/src/agenda/)和[同步实现](../../crates/ubaa_core/src/facade/agenda_sync/)为准。产品取舍见[日程设计](../design/agenda.md)。

### App 日程命令

查询、修改、清除和范围导出均为本机操作；仅显式同步访问云盘。命令签名以[命令定义](../../crates/ubaa_command/src/command/agenda.rs)为准，机器输出以 [CLI JSON Schema](cli-json.schema.json) 为准。

## 不变量

- **校园时间与稳定身份。** 按 `Asia/Shanghai` 解释校园日期；查询与全天事件的结束边界排他。发生移动后，完成和删除仍使用原发生身份。教学周规则以学期第一周为基准，持久化采用标准重复规则。展开达到资源上限时整体失败，不交付看似完整的截断结果。

### 持久化与修改

- **账号独立的明文库。** 日程按已核实的随机本机账号别名存入独立私有 SQLite，不区分路线、不依赖缓存密钥，也不提供密码学保密。禁止扫描或认领其他库。普通打开不重建损坏或不支持的库，不恢复已停用账号。缓存清除、重建及退出不清除日程；删除日程需要独立操作。见[存储决定](../protocol/decision-log.md#2026-10-31日程改为逐记录明文-sqlite)。
- **关闭先撤销，再收尾。** 退出、换号或重建立即撤销旧代次的新访问，拒绝尚未交付的旧写入。已交给后端的写入收尾后才能释放并重新打开；读取不阻塞关闭，迟到结果不交付。持久禁止恢复与日程关闭独立启动，退出返回前均收尾。直接调用 Core 打开或停用的调用方负责同样的顺序。失败写入不自动重试。

### 学校投影与合并查询

- **学校原状态与本机覆盖并存。** 查询仅消费同账号已取得的学校结果，保留来源、观察时间、覆盖范围与缺口。不把无观察当作学校空结果，不用本机完成、隐藏或重新挂起改写学校状态；清除覆盖恢复学校规则。首页复用已取得的结果，不额外请求学校或更新观察时间。缓存不可用时，本机日程仍可查询。
- **选课冲突只作提醒。** 用本机日程和校园时间比较严格相交的有效时段，首尾相接不冲突。隐藏、已完成、同一已选课程、仅有截止时间或缺失时段的事项不纳入。失败或缺口要提示；选择继续仍须用新鲜在线资格和原确认流程提交。

### 跨设备同步

- **不可变发布与完整拉取。** 各设备按持久身份和发布序号创建独立快照，不覆盖共同文件。完整遍历目录并读取选定正文后才原子合并；记录冲突按记录版本排序，同版本不同内容拒绝合并。自动同步默认关闭，只读拉取不授予写许可。启用确认须绑定当前账号、客户端及策略；Auto 和 Direct 均使用云盘直连，不依赖网关观察，显式 WebVPN 不允许启用。换号、路线或客户端变化后须重新确认。证据见[日程对照](../protocol/parity/agenda.md)。
- **先登记尝试，再发送。** 每账号保留唯一在途尝试，其他进程只能核对。明确成功的最终回执加当前元数据和完整正文才能确认发布，且只清理未变化的本机记录。未知结果不换名重传。清除本机数据不删除云端、不重置发布序号；保留可能已发送的无正文身份，未决前不分配新序号。紧凑删除摘要防止旧快照复活，云端历史不自动清理。

### RFC 5545 范围快照导出

- **范围快照。** 导出使用本机一致的日程快照及同账号已有学校缓存，不在线刷新。每次重复发生独立导出且身份稳定，不承诺导回重复系列。未知时段跳过并报告数量；预算不足或缓存读取失败不静默退化成不完整文件。

## 错误语义

- 资料库损坏、版本不支持、账号不匹配和展开超限分别失败，保留原文件或事务状态。学校缓存故障单独报告；在允许降级的查询中仍返回本机内容，不能把本机日程故障当作重建学校缓存的理由。
- 旧代次返回 `superseded` 仅表示结果不可交付，不证明已交后端的写入没有提交。调用方重新打开后先读取现状，不自动重做。
- 同步不可用、目录不完整、同版本冲突、确定拒绝及远端结果未知分别报告。读取不到目标不证明未写入；保留待核对状态和本机待同步记录。
