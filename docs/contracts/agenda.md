# 日程 Core 合同

日程一期 1a 只提供本机自建事项、标准重复展开和学校事项的本地覆盖层。所有生产入口从 `ubaa_core::facade` 导出，不调用学校网络，不包含学校来源投影、同步、导出或宿主接线。[设计稿](../design/agenda.md)描述完整产品目标，[存储与依赖决定](../migration/decision-log.md#2026-10-31日程使用独立账号密文库与标准重复规则)记录本期取舍。

## 时间与事项

`AgendaTime` 保存带偏移量的时间和 IANA 时区标识。`new` 将输入时刻转换成 `Asia/Shanghai`，写入时核对时区、偏移量和秒精度。`AgendaItem` 使用 UUID，包含 `AgendaContent`、标准 RRULE 正文、EXDATE、单次覆盖、完成记录、创建/修改/删除时间及 `locally_modified`。

事件必须有开始和结束，结束严格晚于开始。全天规则的 DATE 形式 UNTIL 按校园零点展开，不依赖宿主时区。全天事件使用零点边界，结束日期不包含在事件内。待办可有截止时间或无日期。重复事项必须有开始或截止时间。覆盖与完成的键使用原始发生时间的规范 RFC 3339 字符串，无日期待办的完成键为 `undated`。单次覆盖移动到其他日期后，完成和删除仍使用原始发生时间。

`expand_agenda(item, from, to)` 与 `AgendaStore.query(from, to)` 返回 `[from, to)` 内相交的事件、范围内到期的待办及无日期待办。结果包含 `item_id`、`recurrence_id`、实际内容、`completed_at` 和 `overridden`。查询上限为 3,660 天，单系列展开使用 rrule 的有限迭代，达到 65,535 次发生或库内部限制返回 `CacheError::Capacity`。查询不会把截断结果当作完整结果。

`teaching_week_rule` 接收学期第一周周一、起止周、每周/单周/双周、星期、时间与跳过日期，输出开始时间、标准 RRULE 和 EXDATE。单双周以学期第一周为基准，存储不包含教学周专用语法。

## 持久化与修改

`AgendaStore.open(root, account, key)` 接收已核实账号的随机 32 位十六进制别名和安全存储密钥。账号身份核实与密钥保留由宿主负责。日程密钥的生命周期必须跟随日程数据，清理或轮换只读缓存密钥时必须保留原日程密钥。日程独立保存于账号密文库，数据库没有路线维度。只读缓存的容量淘汰、清理、重建均不作用于日程。普通打开保留退出状态，宿主必须在退出时调用 `deactivate`，在同账号重新登录后调用 `activate`。持久退出栅栏作用于所有连接；切换账号必须更换句柄并隐藏旧投影。

`create/get` 创建与读取原始事项。创建会把本地修改标记设为 true，已有 UUID（包括删除标记）不能覆盖。`edit/delete` 接收 `AgendaEditScope`：仅此次、此次及以后、全部。针对发生的操作必须提供原始时间，无日期事项传入 None。编辑传入完整新内容及规则，仅此次编辑重复事项时保持系列规则。后半段编辑返回新 UUID，系列拆分在一个事务内完成。相同规则的平移保留剩余 COUNT、例外和完成记录；新规则无法产生的例外随整体规则替换移除。`complete` 记录或取消某次完成，取消后保存明确的空完成时间。单次删除后的发生不能再完成。

`SchoolAgendaKey` 以来源和上游稳定标识组成键。`set_overlay/overlay/clear_overlay` 设置、读取和清除完整覆盖。覆盖记录存在、未删除且 `completion_override = true` 时，`completed_at` 是否为空直接决定列表完成状态，`effective_completed(upstream)` 实现这一规则。只设置隐藏或备注时传入 `completion_override = false`，继续沿用上游完成状态。隐藏和备注保留在覆盖层，学校来源状态由后续投影任务传入。清除覆盖写删除标记并恢复上游完成状态。

所有本地修改写入 `updated_at` 和未同步标记，发生错误时事务回滚。调用方传入当前校园时间，早于原记录修改时间的写入会被拒绝。`unsynced_count` 包含事项、覆盖和删除标记。`clear_local_data` 显式删除当前账号全部日程并返回清除前未同步记录数，宿主可先查询数量再展示确认。`purge_tombstones` 仅移除严格超过 180 天的删除标记，包含尚未同步的删除标记。同步确认和跨设备合并属于后续任务，本期没有清除未同步标记的公开入口。

日程磁盘 schema 为 1，密文上限 16 MiB。账号状态保存在一个密文行，校验失败会阻断整个账号的日程读取，原文件保留供后续恢复。未知版本、错误密钥、损坏数据和不安全路径返回稳定本地错误，保留原文件并拒绝降级明文。错误类别复用 facade 的 `CacheError`，不携带路径、SQL 或业务正文。Core 新增 API 不改变 CLI schema v12 和 Bridge v43。
