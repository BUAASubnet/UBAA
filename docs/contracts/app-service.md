# 应用服务合同

## 概念

图形宿主和 App 命令通过 Rust Core 使用独立的 Node.js 应用服务：启动配置提供更新和公告，Core 解释学校请求的更新门控，遥测负责使用统计及撤回后的数据删除。接口和字段以 [JSON Schema](app-service.schema.json)、[Core 客户端](../../crates/ubaa_core/src/app_service/)和[服务端实现](../../services/app_service/src/)为准。实际部署与保留期见[部署手册](../runbooks/app-service.md)和[隐私政策](../site/tech/privacy-policy.md)。

## 不变量

- **与学校隔离。** 只使用独立 transport 和构建配置的服务地址，不做 Direct/WebVPN 转换、不携带学校凭据、不跨主机跳转。Release 必须校验 HTTPS；非 Release 仅可显式联调本机回环。无有效地址、渠道或版本时整体停用；运行时条件只能关闭遥测，不能开启服务。硬关闭时不显示可用统计开关。普通诊断和主动完整报告均不自动上传。

<a id="31-状态"></a>

- **宿主确认和统计权限独立。** GUI 登录、恢复前检查本机已接受当前政策，拒绝时保留账号材料并留在登录页；确认前唯一的服务请求是重试已有删除标记。共享状态独立管理是否同意、需要重新同意或基础模式；命令不弹窗、不获取启动配置，非同意状态不发送应用服务请求。登记较新政策保留统计开关、安装 ID 和基础模式，旧构建不覆盖较新登记。首次或重新确认开启统计；旧基础模式须在设置中确认才重新启用。关闭统计清空待发批次及计数，启动配置不受影响；撤回应用服务同意则停用启动配置和门控。
- **政策正文单一来源。** [隐私政策](../site/tech/privacy-policy.md)嵌入 GUI 与命令构建，供离线阅读。收集项目、目的、接收方、存储地点、保留期或用户权利变化须升政策版本；仅修正文案不升版，正文变化仍更新摘要。修改披露范围须和实际采集、删除及留存一致。

<a id="7-用户派生标识与年级"></a>

- **最小统计。** 安装 ID 为随机标识；仅确认了当前账号时可按白名单发送学号派生标识及年级，不上传学号原值。服务器再用私有密钥派生去重键，只保存服务端结果；密钥不进入客户端、CI 或仓库，不例行轮换，泄露更换后记录去重断点。未知年级不猜测；本科学号长度无可靠证据，不据此识别或校验。无账号只统计设备；分钟级聚合不含安装或用户标识，活跃分组的去重计数不可相加推算总量。不得上传原始响应、凭据、私人内容或任意错误文本；仅允许经过明确筛选的安全诊断字段，不保存 IP 或请求正文。启动配置不带安装或用户标识，公告已读状态留在本机。
- **批次与删除互斥。** 未确认批次与待发计数均属于待发数据；批次冻结后以相同身份重试，重复提交只计一次。GUI 与命令共用本机队列。删除先持久标记并停止跨进程入队和上传，成功后原子清理队列、轮换安装 ID 和清标记；失败保留标记。服务端按安装串行上报和删除，对旧 ID 拒收，晚到批次不能重建已删除明细。删除不影响已定稿的匿名聚合和不含标识的分钟计数，未定稿聚合按剩余明细重算。
- **门控只限制学校请求。** 门控仅在已同意、同渠道且当前版本低于最低版本时生效。本地日程、缓存和导出继续可用。只有有效启动配置可以设置或解除门控；未知状态或请求失败保留原记录，撤回同意暂停门控，重新同意则刷新配置。用户主动学校操作显示更新入口，后台失败只显示横幅，命令按稳定错误退出。门控防止已知不兼容的学校请求，不用于强制升级。
- **兼容与发布。** 删除或重释响应字段须同步升级客户端、Schema 和服务端校验；兼容扩展只加可选字段或枚举值。客户端忽略未知字段，未知更新状态按未确定处理，坏公告不拖累其余配置；已知顶层或更新结构不合法时拒绝整份响应。版本比较先用 SemVer，再用数值构建号区分同一发布序列。先使服务端理解新增白名单维度，再发布会上报该维度的客户端；汇总先计算再清理过期明细。来源取舍见[应用服务对照](../protocol/parity/app-service.md)。

## 错误语义

- 遥测收到成功回执即结束批次，包含重复提交；已识别的负载拒绝丢弃批次，安装删除回执结束该批次。未识别的响应、超时、限流及暂时服务故障按有界策略处理相同批次，不复用批次身份发送不同内容。具体 HTTP 状态、机器码及重试条件以 [服务端路由](../../services/app_service/src/server.ts) 和 [Core 上传实现](../../crates/ubaa_core/src/app_service/upload.rs)为准。
- 删除是幂等的；失败或结果未知仍提示待完成并保持上传停用。GUI 可按既有触发条件重试；未同意的命令不替用户重试。删除标记与开关状态分开，不因一次网络失败丢弃标记。
- 无效或取不到启动配置不应阻断本地功能，也不覆盖最后有效配置。门控状态读失败只记录安全诊断，当次学校请求照常；生效时返回不可重试的 `update_required`，已发批次保留逐项结果，未发项不得发送。
