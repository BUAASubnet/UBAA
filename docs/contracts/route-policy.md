# 路由策略合同

## 概念

Core facade 负责探测校园网络、解析功能路线、检查会话与执行读取回退。宿主交付 Core 的实际路线与诊断，不重建策略。配置和诊断类型以 [Core 配置](../../crates/ubaa_core/src/config.rs) 和[路由实现](../../crates/ubaa_core/src/facade/routing.rs)为准；会话隔离见[连接与会话合同](connection-and-session.md)。

## 不变量

- **显式策略不探测、不回退。** 缺少配置时使用 Auto；显式选择的网络状态未探测，不能当作校外。Auto 只在总预算内探测校园网关的私网 TCP 地址，不发送 HTTP/TLS 或认证材料；公网地址、代理假地址和不可达结果不当作校内。并行观察共享探测，失效后不得采用旧结果。

### 校外域名配置

- **校内优先 Direct，校外按实际域名选择。** 校外内置名单以 [域名策略](../../crates/ubaa_core/src/facade/routing/domains.rs)为准。名单外通常先试 Direct；网络不可达、超时或确认的校园网限定提示才允许 Auto 读取转 WebVPN 一次。若初始判断校内，先重新探测。只有相同域名的 WebVPN 业务解析确实成功才记限时偏好，静态兜底不算成功。偏好按失败主机记录，不延长、无账号信息；回校内或偏好路线网络失败时撤销。缺目标会话则记录短期恢复需求，不能以核验另一条路线代替。

名单依据为 2026 年 11 月 13 日的校外匿名入口观察：希冀 HTTPS 及 iClass 的三个业务端口在 5 秒和 8 秒预算内均超时；i 北航在两个公共 DNS 服务中返回 NXDOMAIN；UC 完成 TLS 后 HTTP/2 异常关闭，HTTP/1.1 用户入口和根页面均返回空响应。公开入口成功或跳转只证明入口可达。财务按维护者确认使用 WebVPN，实际业务证据见 [PR #124](https://github.com/BUAASubnet/UBAA/pull/124)；探测环境见[认证对照](../protocol/parity/auth-session.md#2026-11-13-校外域名名单)。

图书馆借阅只支持 Direct。2026 年 11 月 23 日的验证中，WebVPN 把借阅列表请求重定向回未代理的 `space.lib.buaa.edu.cn`。Auto 下的读取、续借和核对均不回退到 WebVPN；显式选择 WebVPN 时提示切换为自动或直连。详见[当前借阅与续借](../protocol/parity/campus.md#当前借阅与续借)。

- **会话按路线核验。** 校内 Auto 登录只准备 Direct，校外 GUI 可并行准备两条，一条就绪不等待另一条人工验证码。恢复只检查所需路线，不复制 Cookie、Token 或登录状态。自动登录由共享服务按账号、路线和保存许可约束；非保留登录只核验本次已绑定的会话。
- **网络变化只取消普通读。** 宿主保留同类型换网事件，合并重复通知并采用最新观察。断网保留数据，重连在同一预算内完成探测、恢复和原范围重读；回校园网可让已有正常 WebVPN 读取收尾。换网观察不等待业务锁，不影响已发写入、固定路线读回和云盘传输。
- **写入与缓存边界。** 写入在发送前锁定实际路线，最终请求和写后核对都不跨路线、不重发。业务缓存可按账号和精确查询跨路线只读显示，不授予写资格。云盘文件传输仍使用已支持的 Direct，不借普通网页回退开放 WebVPN。

## 错误语义

- 网络不可达可按 Auto 规则切换；认证、权限、业务拒绝、解析错误和 HTTP 5xx 不触发此回退。会话不足交给所需路线恢复，超时保留已显示内容，必要时提示重新连接或手动登录。非法配置返回输入错误，不改成 Auto 静默继续。

### 校园网限定提示页

- **按发送边界处理校园网限制。** Direct 的成功 HTTP 响应只有匹配精确、短小的“请在校园网环境下访问”单标题页，才归为 `campus_network_required`；普通业务 HTML、WebVPN 同页不套用此分支。Auto 普通读按上面的条件回退，显式 Direct 或写前遇到时返回不可自动重试的网络错误。最终写发送后结果未知，保留原路线核对。云打印停止启动后续项，评教区分尚未尝试和结果未知。

依据：2026 年 11 月 20 日北京时间 01:41 的 Android 诊断中，博雅、教务、研讨室和阳光打卡的校外直连接到相同的 HTTP 200、69 字节单标题页，用户确认限制分时段生效。冻结旧版和 buaa-api 无等价分支；此识别不改变各业务的认证、请求参数和解析。实现以 [Core 路由与错误处理](../../crates/ubaa_core/src/facade/routing.rs)为准。
