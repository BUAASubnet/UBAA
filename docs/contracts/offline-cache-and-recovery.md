# 离线缓存与恢复合同

## 概念

Core 持有学校业务缓存和读取票据；平台持有私有目录、随机账号索引和安全密钥；GUI、命令及 Bridge 只读取稳定投影、协调恢复及显式维护。数据与接口以 [Core 缓存](../../crates/ubaa_core/src/cache/)、[离线 facade](../../crates/ubaa_core/src/facade/offline.rs)、[Dart 恢复](../../packages/ubaa_app/lib/src/controller/recovery/)和[平台账号材料](../../packages/ubaa_platform/lib/src/material/)为准。业务缓存不存储主会话与业务令牌，[日程](agenda.md)亦独立存储。

## 不变量

- **账号和安全材料。** GUI 与命令共用稳定的随机账号别名，不用学号、遮罩或显示姓名推断账号。业务正文和敏感查询条件使用账号密钥认证加密，与密码分开保存；不能降级明文、固定密钥或为旧库自动补替代密钥。退出或清缓存保留账号映射和原密钥，不连带清除日程。只有身份明确且允许恢复的本机账号可从启动进入离线首页，索引或安全材料异常时保留原材料。
- **精确范围和来源。** 键包含账号、操作与完整业务条件，不包含路线。Direct/WebVPN 共用同账号同查询结果，实际路线记录来源；会话、业务令牌、写资格和未知结果提示仍绑定原路线。保留结果的取得时间、范围和完整性，不能把失败的尝试记为新取得或续期，不能跨日用旧今日课表。
- **发布须持有效票据。** 账号、请求、路线变更或清理撤销旧操作；写入和交付时再次核对作用域及版本。跨进程同查询竞争可复用同世代的较新完整结果，已收齐结果最多重领票重试一次本地发布，不重发学校请求。业务写入后的范围失效开启新查询世代，旧结果不得借新修订复活。明确清理在事务中推进代次并废弃旧句柄，已退出账号不得借清理重新打开。
- **只按已证实的范围替换。** 完整成功或有依据的空结果才替换完整集合。分段进度不冒充上游游标或完整集合；局部失败保留旧数据，不让部分分页、基础详情或错范围响应覆盖完整快照。逐周完整导入原子发布，普通子查询按各自取得修订比较。博雅普通选课和详情仅在线读取；默认希冀刷新只处理校历确认的活跃范围，显式历史读取仍可用。
- **缓存不可写。** 不保存 intent、句柄、操作资格、敏感位置、照片、锁码、原始响应和认证材料。命中缓存后必须在线重读目标与资格；确定写入按实际影响范围失效缓存。未知结果线索仅用于重启后原路线只读核对，不恢复写意图或自动重发。
- **恢复和调度。** 先检查目标路线的现有会话，再按明确许可决定能否用保存的密码重新登录。未记住密码时仅可核验当前控制器已绑定的会话，不采用继任快照；明确需要人工登录时转登录入口。网络抖动保留原查询和数据，前台、当前可见查询和写入核对优先于后台预取；恢复或替换客户端须先收束已交付写入。

### 同账号资料的连续展示

- **展示独立于认证。** 缓存资料保留学校已提供的展示值，不还原遮罩，不保存证件或登录材料。网络和后端重建只撤销旧读取与动作，同账号页面保留导航、筛选、滚动、分页与草稿，完整新结果到达再替换。云盘按原逻辑路径重新获取句柄，不跨客户端复用；确认换号、退出、路线范围变化或显式清除才清理受影响的展示范围。
- **财务旧记录兼容。** 财务收入快照保留可选的部门名称、项目编号和项目名称。旧记录缺少这些字段时仍可读取，缺失值为 `null`，缓存格式版本不变。

## 错误语义

- 缓存缺失、不可用、密钥错误、损坏、版本不支持、资源忙和超限分别处理；格式不兼容只允许用户显式重建。允许时继续在线只读，保存失败不能掩盖已取得的在线业务结果。清除失败保留原句柄和内容；清除成功后的压缩失败单独报告，不声称已经回收磁盘空间。
- 被替代的票据不交付旧结果，也不能证明远端失败。完整结果未到或刷新失败时保留可用旧内容并标明来源与失败；退出、清理或写后失效的内容不能用旧缓存补回。
- 网络与暂态上游失败保留当前账号和可用页面。会话确实失效且无法继续恢复时要求人工登录；后台不反复弹验证码或提交凭据。写入结果未知遵守[单次发送与读回](flutter-bridge.md#6-写-intent)。
