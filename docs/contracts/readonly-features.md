# 只读功能合同

## 概念

CLI、Bridge 和界面通过 [Core 只读 facade](../../crates/ubaa_core/src/facade/read/) 访问学校功能。Core 选择路线、解析响应并交付 typed 业务值；命令及参数以[命令定义](../../crates/ubaa_command/src/command/)为准，JSON 格式以 [Schema](cli-json.schema.json) 为准。逐操作协议和发布验证范围分别见[协议依据](../protocol/README.md)和[项目现状](../project/status.md)。

## 不变量

- **只读和路线所有权。** 宿主不能从读取入口提交、上传或修改学校业务，不导入上游实现，不构造上游地址或重建路线。普通结果只包含允许公开的 DTO 和安全路线信息，不交付原始 HTML、签名或认证材料。研讨室锁码是否可用和专用短期显示分别处理，通用命令与验证只报告可用性。
- **精确范围和来源。** 成功空结果必须有有效响应依据，不能由缺字段、范围不符、权限拒绝或未完成分页推得。静态用途兜底标明来源，不能作为实时成功或路线偏好的依据。SPOC、希冀隐藏诊断只提供安全计数和普通业务结果；一次验证固定路线，认证失败后逐项标记阻塞。
- **学业身份和学期。** 本科与研究生按门户在线身份分流，身份绑定路线和认证代次，不用学号、学期编码或错误猜测。GSMIS 当前学期采用学校标志，作息方案只能在唯一时补全；考试学期与课表学期分开。历史最近学期不自动成为当前学期，成绩统计以 Core 有效学分计算结果为准，无有效分母时保持未知。
- **账户指标和流量。** 已取得的独立指标即使其他项失败仍可显示；有效零值区别于缺失。新在线免费剩余含套餐，旧快照可明确标为未含，计费余额不加套餐。邮件、图书数量不推导具体内容，云盘剩余指标不授予云盘操作权限。
- **作业与校园服务。** 作业保留目标身份、完整度和未知提交状态，不能用列表摘要代表未取得的正文。当前范围与历史刷新分别处理。iHome 公开、本人、关注等范围保持区分，不将原始用户对象或联系信息作为公开输出；命令的读取能力不等于关注或支持的写入授权。

### 财务收入

- **财务按完整账号范围读取。** 访问采用有证据的 WebVPN 路线，全部分页成功后才发布完整快照。人民币金额保持精确且区分空值和零；证件、银行账号、门户票据和 Token 不进入公开结果或缓存。接口以[财务 facade](../../crates/ubaa_core/src/facade/finance/)为准。

## 错误语义

- 网络失败与超时可按[路线合同](route-policy.md)恢复只读操作；认证不足恢复目标路线。权限、业务拒绝、上游结构变化和解析错误分别上报，不以换学籍系统、改范围或返回空集合掩盖。
- 账号所有权冲突或整体认证失败终止查询；独立指标失败保留其他成功项，调用方检查每项状态，验证工具不能用整体成功掩盖失败项。
- 未知学籍或尚无证据支持的研究生考试明细按不支持处理。缓存命中、静态展示和已在线证实的结果分别标注；失败或部分结果不能覆盖完整缓存。
