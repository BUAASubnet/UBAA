# 课表与考试

本页介绍怎样查看每周课表和考试安排。

## 在哪里找到

- 课表：导航“学习”→“课表查询”。首页的“今日课表”卡片（晚上会显示“明日课表”）也可以点开课表。
- 考试：导航“学习”→“考试查询”。

## 查看课表

1. 进入课表后显示当前教学周，七天按节次排列。
2. 用表头的“上一周”“下一周”切换，也可以在课表上左右滑动；点周次标题可以“选择周次”。
3. 点右上角的“学期”切换学期。
4. 点课程查看详情，包括时间、地点、教师、周次和学分。同一时段有多门课时，会合并显示，点开后逐门查看。

应用根据学校门户确认的身份选择本科或研究生教务系统。研究生默认显示学校标记的当前学期，也可以手动选择其他学期。

## 查看考试

考试页按时间排列即将到来的考试，显示日期、倒计时、时间、考场和座位号；已结束的考试收在“已结束考试”中。

- 点筛选按钮可以选“全部”“已安排”“未安排”，并切换学期。
- 搜索框可以按课程或考场搜索。

## 注意事项

- 调课、补考和临时通知可能还没同步到学校系统，重要安排请同时核对学校通知。
- 研究生有考试明细时，页面目前会提示“暂不支持”，不能据此判断没有考试。
- 读取失败时页面会显示“重试”，读取失败不代表没有课或没有考试。

课表也会出现在[日程](/features/agenda)中。网络或登录问题见[常见问题](/tech/troubleshooting)。
