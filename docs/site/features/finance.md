# 财务查询

本页介绍怎样查看学校财务系统中的个人收入记录，例如酬金、助学金等发放记录。

## 在哪里找到

导航“校园”→“财务查询”。此版本没有这个入口时，表示当前安装包暂不支持财务查询。

## 查询记录

1. 在年份选项中选择某一年，或选“全部”。
2. 页面顶部显示当前范围的实发合计，以及笔数、应发和扣税。
3. 记录按所属月份分组，每组标题显示当月实发小计。
4. 用“搜索项目或摘要”缩小范围，合计会随搜索结果变化。
5. 点一条记录查看应发金额、扣税、实发金额、税率、所属年月、录入日期和流水号。

功能是否可用取决于你的账号在学校财务系统中的权限。

## 刷新与离线查看

打开时先显示本机保存的记录，并标注“离线记录”，在线读取成功后更新。刷新失败时保留上次的记录。需要手动更新时点“刷新”。

## 注意事项

- 记录来自学校财务系统的录入信息，到账以银行为准。实际到账时间和金额请核对银行记录，有疑问请向学校相应部门确认。
- 反馈问题时不要公开收入明细、账号信息或完整截图。
