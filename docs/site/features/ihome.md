# iHome

本页介绍怎样在 UBAA 中浏览学校接诉即办平台（iHome）的诉求、回复和公告。

## 在哪里找到

导航“校园”→“iHome”。页面顶部可以在“诉求广场”“我的诉求”“我的关注”“我的评价”之间切换，旁边的“公告”查看平台公告。

## 查找与阅读

1. 用“搜索诉求或回复”输入关键词。
2. 用“分类”选择诉求类别，用“排序与状态”选择排序方式（默认排序、最新发布等）或只看“已回复”“未回复”。
3. 点“查看详情”展开诉求正文、官方回复和“处理进度”，正文可以选择和复制；再点“收起详情”收起。
4. 列表底部点“加载更多”继续浏览。

“我的评价”中会显示你给出的评价内容，以及响应速度、满意度和解决程度。

## 关注与支持

诉求旁的“关注”和“支持”按钮可以点选或取消，确认后提交一次并刷新结果。结果不确定时会提示刷新，先核对状态再决定是否重试。

## 注意事项

- UBAA 不提供新建诉求、提交评价、评论或附件预览，这些操作请到学校 iHome 平台。
- 反馈问题时，不要公开本人或他人的诉求内容、联系方式和完整页面截图。

网络或登录问题见[排障指南](/tech/troubleshooting)。
