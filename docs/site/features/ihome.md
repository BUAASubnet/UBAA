# iHome

查看接诉即办平台的诉求广场、我的发起、我的关注、我的评价和公告。

## 查找与阅读

在诉求广场搜索诉求或回复，并按类别、回复状态和时间排序。展开诉求可以查看正文、官方回复及处理历史，正文支持选择和复制。个人视图和公告提供各自的列表与详情。

## 关注与支持

在允许操作且状态已知时，可以关注、支持或取消对应状态。确认后应用提交一次并读取结果。结果不确定时，先刷新详情核对状态，再决定后续操作。

## 当前范围

本模块不提供新建诉求、提交评价、评论或附件预览入口。分页数量取决于学校接口；重复返回的记录不会被当作新的内容持续追加。

不要在公开反馈中贴出本人或其他人的诉求隐私、联系方式与完整页面截图。
