# 教学评教

本页介绍怎样查看待评课程并提交评教。

## 在哪里找到

导航“学习”→“教学评教”。

## 提交评教

1. 进入后，待评课程排在前面，已评课程收在“已评 N 门”中。
2. 勾选要提交的课程，也可以用底部的“全选”一次选中全部待评课程。
3. 点“提交 N 门”（只选一门时为“提交评教”），在确认框中核对课程数后点“确认提交”。
4. 提交完成后，分别查看成功、失败、结果未确认和尚未执行的课程。

标有“不可评”的课程当前不允许提交，点课程可以查看详情和原因。点筛选按钮可以只看“待评课程”，搜索框可以按课程或教师查找。

## 注意事项

- 评教提交后不可修改，提交前请确认。
- 批量提交时，如果某门课程结果未确认，后续课程会停止提交。先到学校系统核对，已经成功的课程不要重复提交。

网络或登录问题见[常见问题](/tech/troubleshooting)。
