# 图书馆座位

本页介绍怎样预约图书馆座位，以及查看和取消预约。

## 在哪里找到

导航“校园”→“图书馆座位”。页面顶部有两个分段：“预约座位”和“我的预约”。

## 预约座位

1. 点右上角的楼馆按钮切换校区图书馆。
2. 选择楼层和分区，选项旁会显示空座数，例如“空 12/80”。
3. 选择日期和时段。
4. 在座位图中点一个可预约的座位，确认“已选座位”和时间后，点“预约此座位”。

点“查看座位分布”可以打开分区的静态示意图，支持放大缩小。示意图的颜色不代表座位是否可用。

## 查看和取消预约

在“我的预约”中查看已有预约的区域、座位、时间和状态，点详情可以看到预约编号。需要取消时点“取消预约”，确认后提交。取消后座位可能被他人预约，无法恢复。

## 注意事项

- 座位和时段随时可能被其他人占用，列表中可选不保证最终预约成功。
- 提交后到“我的预约”核对结果。提示“结果未确认”时，先刷新核对，不要直接重复提交。
