# 登录与连接方式

本页介绍怎样登录 UBAA，以及如何选择连接方式（自动 / 直连 / WebVPN）。

## 登录

1. 打开应用，在“UBAA 登录”页输入学号和密码。
2. 按需勾选“记住密码”和“自动登录”，点“登录”。首次登录或隐私政策更新后，需要勾选同意《隐私政策》，也可以在登录弹窗中同意。
3. 学校要求图片验证码时，应用会先自动识别；识别不成功会弹出“登录验证”，输入图片中的字符后点“验证”。看不清就点图片刷新。

“记住密码”和“自动登录”依赖系统安全存储。当前平台不支持时，这两项不可勾选，密码只在本次运行中使用。

勾选“记住密码”并成功登录后，普通退出和退出后的重启都会回填账号与密码，等待你手动点击登录。登录页的“隐私政策”可以打开应用内保存的政策全文，无需联网。

登录失败时，可点错误提示下方的“诊断信息”并分享完整诊断文件。文件含学校返回的原始内容，可能包含个人信息和登录凭据。请通过私下渠道发送给维护者，切勿公开发布。

## 选择连接方式

在设置的“连接模式”中选择：

| 选项 | 适合场景 |
| --- | --- |
| 自动 | 大多数情况。应用判断你是否在校园网内，自动选择直连或 WebVPN |
| 直连 | 在校园网内，设备直接访问学校系统 |
| WebVPN | 在校外，通过学校 WebVPN 访问学校系统 |

无论选哪一项，请求都由你的设备直接发往学校，UBAA 没有中转服务器。

### 自动模式怎样工作

- 在校园网内登录只准备直连，查询也先走直连。
- 在校外登录时同时准备直连和 WebVPN，任意一种可用就能进入应用；另一种暂时没准备好不会阻挡你。查询同样先试直连。
- 查询遇到网络不通或超时时，会改用 WebVPN 重试一次。在校外直连遇到“请在校园网环境下访问”提示时，也会尝试 WebVPN。登录失效、权限不足或学校拒绝等问题不会切换。
- 改用 WebVPN 并成功取得同一学校系统的数据后，接下来 24 小时内该系统优先使用 WebVPN，之后再试直连。
- 网络变化或应用回到前台时，会重新判断网络并恢复需要的连接。

固定选择“直连”或“WebVPN”时，只使用该方式，不会自动切换。切换连接方式不会清空已缓存的课表、作业等内容。

### 提交操作与连接方式

选课、预约等提交只在发送前选择一次连接方式，之后不会换一种方式自动重发。网络中断导致结果未确认时，请先到记录页核对，不要重复提交，详见[常见问题](/tech/troubleshooting#操作后提示结果未确认)。

## 连接状态与恢复

- 设置页“连接模式”下方显示“当前连接：直连”或“当前连接：WebVPN”。
- 连接出现问题时，标题栏右上角会出现连接状态按钮，点开可“重试”；提示“完成登录”时，按提示重新验证即可。处理办法见[常见问题](/tech/troubleshooting#标题栏出现连接提示)。

## 退出与清除

“退出登录”和“退出并清除本机数据”在设置页“账号”分组中，手机上“我的”页底部也有“退出登录”。两者清除的范围见[怎样清除](/tech/data-and-privacy#怎样清除)。

遇到问题先看[常见问题](/tech/troubleshooting)。
