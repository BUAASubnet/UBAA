# 登录与连接方式

UBAA v2.0 提供直连和学校 WebVPN 两条路线。在设置中可以选择自动、直连或 WebVPN。

| 选项 | 使用方式 |
| --- | --- |
| 自动 | 根据校园网络探测结果选择路线；探测失败或会话未就绪时按提示处理 |
| 直连 | 设备直接访问学校业务系统，适合具备校园访问条件的网络 |
| WebVPN | 通过学校 WebVPN 访问业务系统，适合校外使用 |

自动是一种选择策略，实际请求仍通过直连或 WebVPN。新版不提供 UBAA 服务器中转。

## 登录与恢复

输入账号、密码后，应用准备两条路线的登录状态。某条路线失败时，已成功的路线可以保留；是否继续使用取决于当前连接设置和页面提示。

手动登录支持学校要求的图片验证码。验证码等待期间不会获得提交权限；取消或离开登录流程后，需要重新开始验证。

应用可恢复本地账号与缓存，并在需要时检查会话。网络超时与登录失效是不同问题：先检查网络和连接方式，确认登录过期后再重新登录。

## 保存与清理

记住密码依赖设备安全存储。退出登录、清除已保存账号、清理业务缓存有不同作用，请根据设置页的具体提示选择。
