# 课程

打开“学习”，顶部可以直接进课表、作业、考试和成绩。“本学期课程”把还有排课的课程列在前面，其次是已结课的课程，只有 SPOC 的课程排在最后。课程行显示下次上课的时间和地点。有待交作业时显示数量；来源不全时写作“已知 N 项待交”。来源读取失败时，可以点提示条上的“重试”。

## 查看一门课

点课程名进入课程主页。同一教务课程代码的多个 SPOC 教学班放在一起。只有 SPOC 记录的课程也能打开，页面会说明未关联课表。

- **作业**：待交作业分为 SPOC 和希冀两组，各组按截止时间排列。已截止未交和已提交的作业折叠显示。点作业进入原来的详情页，返回后继续看这门课。
- **课堂**：查看各教学班的直播和回放。只有一个教学班开通课堂时直接显示，有多个时可以切换。
- **课件**：浏览教学班的文件夹和课件。多个教学班中，空目录不单独列出。
- **信息**：查看排课、周次、教师、学分，以及已读到的本学期考试和成绩。可在这里取消或恢复希冀课程关联。

本科生导入本学期课表后，如果希冀课程名称唯一匹配，且至少一项作业的开始或截止日期落在本学期内，应用会自动关联。比较名称时忽略空白和全半角括号的差别。取消关联只影响本账号、本学期的归类，不删除作业。

研究生和身份尚未确认时，课程列表只用 SPOC 课程，不并入教务排课、考试和成绩，也不自动关联希冀。学期不明或未导入课表时，同样可以查看 SPOC 课程。

## 跨课程查找

顶部的“作业”打开“全部作业”，汇总已读到的 SPOC 和希冀作业，可按课程筛选。未归到本学期课程的作业保留来源提供的课程名。

“学业”下有博雅课程和评教。“按来源浏览”保留 [SPOC 作业](/features/spoc)、[希冀作业](/features/judge)和[每日课程](/features/daily-courses)的原入口；要查往年希冀作业，从希冀作业页进入。
