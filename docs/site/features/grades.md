# 成绩查询

本页介绍怎样按学期查看成绩、学分和平均分。

## 在哪里找到

导航“学习”→“成绩查询”。有新成绩时，首页会提示“某门课 成绩已更新”或“某学期 有 N 门成绩更新”，点“查看”直接打开，点“忽略”关闭提示。

## 查看成绩

1. 页面顶部是成绩汇总：所选学期的加权平均分、算术平均分、课程门数和学分，底部一行是“全部学期”的统计。
2. 用“上一学期”“下一学期”切换，或点学期名称从列表中选择。
3. 下方每门课显示分数、学分、课程属性和成绩类型。不及格的分数以红色标出，未公布的显示“待出”。
4. 用搜索框按课程名称查找；点筛选按钮可以只看“已出成绩”或“待出成绩”。

研究生可以查看历史成绩，以及学校提供的总体和分学期统计。

## 注意事项

- 全部学期统计需要逐个读取学期，读取未完成时会显示“部分统计”，并注明已读取的学期数。
- 未公布的成绩不会被补齐。非数字成绩按学校提供的内容显示。
- 统计口径以页面标签为准，正式成绩证明以学校系统为准。
