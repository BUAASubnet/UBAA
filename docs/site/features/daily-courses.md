# 每日课程

本页介绍怎样查看今日课程的上课状态。

## 在哪里找到

- 导航“学习”→“每日课程”。
- 首页“待办”中也会出现今天待上的课程，卡片上可以直接点“上课”。

## 使用步骤

1. 进入后查看今天的课程，每门课显示上课时间和上课状态。
2. “每日课程”和首页待办的“上课”按钮在课前 4 分钟开放。每日课程页的“上课”按钮最晚开放到上课后 30 分钟，且不超过下课时间。“上课二维码”按钮在课前 10 分钟至下课前提供。
3. 还没到时间的课程显示“HH:MM 起可上课”；已下课仍未上课的显示“未上课”；成功后显示“已上课”。

点筛选按钮可以只看“未上课”或“已上课”的课程，搜索框可以按课程查找。

## 注意事项

- 请遵守课堂要求。操作能否成功由学校系统决定。
- 状态显示不明确不等于未上课。提交失败或提示“结果未确认”时，先刷新查看，必要时向任课老师或学校系统核实，不要重复提交。
- 今天没有课程时，页面会显示“今天没有课程”。

网络或登录问题见[常见问题](/tech/troubleshooting)。
