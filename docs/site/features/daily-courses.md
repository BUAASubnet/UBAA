# 每日课程

本页介绍怎样查看今日课程的上课状态。

## 在哪里找到

- 导航“学习”→“每日课程”。
- 首页“待办”只在校园时间课前 10 分钟至下课时显示签到项，含起止时刻。有当日有效的在线签到目标时，未签到课程可点“上课”，已签到课程可点“二维码”。离线时只显示缓存中的未签到课程，标为“状态待更新”，不能点“上课”。

## 使用步骤

1. 进入后查看今天的课程，每门课显示上课时间和上课状态。
2. 在“每日课程”、首页待办或日程点“上课”，打开二维码面板，再用智慧教室扫码签到。“上课”在校园时间课前 10 分钟至下课时开放，含起止时刻。
3. “每日课程”和日程仍显示全天课程。开放前按钮不可点，旁边显示“上课前 10 分钟开放”。下课后仍未签到的课程只显示“未签到”。扫码成功后面板自动关闭，课程显示“已签到”。
4. 已签到的课程在同一时间窗内显示“二维码”按钮，可以打开面板给同学扫码。面板会继续刷新二维码，也可以保存，由你手动关闭。

点筛选按钮可以只看“未上课”或“已上课”的课程，搜索框可以按课程查找。

## 注意事项

- 请遵守课堂要求。操作能否成功由学校系统决定。
- 签到状态不明确时，先刷新课程。仍未确认时，向任课老师核实。
- 今天没有课程时，页面会显示“今天没有课程”。
