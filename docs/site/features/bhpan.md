# 北航云盘

从“校园”中的“北航云盘”打开文件管理，也可以通过“我的”中的云盘空间入口进入。

## 浏览与管理文件

切换有权访问的文档库，通过目录和面包屑定位文件。可以刷新列表、按名称筛选已加载内容，并查看文件属性。

条目菜单提供重命名、移动、复制、下载、分享和删除等可用操作。新建目录和上传文件使用页面上的对应入口。删除前核对目标，移入回收站后可以在回收站中恢复；永久删除会再次确认。

## 上传与下载

上传时选择本机文件，下载时选择保存位置。应用支持单文件下载，以及目录或多项内容的打包下载；可用方式取决于学校云盘返回的权限。

传输列表显示进度、完成、失败、取消或结果待核对等状态。请求已经发送后中断，云端可能仍有结果，请先刷新目录确认，避免重复上传或覆盖。

## 分享

可以创建、查看、修改和取消自己的分享，设置页面提供的提取密码、有效期和权限。打开他人分享时，按提示输入提取密码，再根据权限下载、另存或上传。

分享链接可能让接收者访问相应文件，请只发给预期的接收者。应用没有全文检索、在线编辑或持久断点续传入口。

## 连接范围

当前以 Direct 路线使用云盘。完整 WebVPN 认证、分享和文件传输链路仍待验证；页面提示路线不可用时，不应把通用 WebVPN 登录成功当作云盘已经可用。
