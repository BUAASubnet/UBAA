# 北航云盘

本页介绍怎样在 UBAA 中浏览和管理北航云盘文件、上传下载、分享和使用回收站。

## 在哪里找到

- 导航“校园”→“北航云盘”。
- “我的”页中的“云盘”空间卡片也可以进入。

进入后默认打开个人文档库。点路径左侧的位置按钮打开“切换位置”：上半部分切换个人、共享、部门、群组等文档库，下半部分“工具”里有“分享管理”“回收站”和“打开分享链接”。

## 浏览文件

- 点文件夹进入，用路径或返回键回到上一级。
- 点“搜索”在当前文件夹中按名称查找；点“排序”按名称、修改时间或大小排序。
- 点文件：可以预览的文件会直接用系统预览打开，其他文件会给出下载选项。

## 管理文件

点条目右侧的“更多操作”，可以：下载、分享、移动、重命名、复制到、查看详细信息、查看分享记录、移入回收站。

- **新建与上传**：点右下角的加号按钮，选择“新建文件夹”或“上传文件”。
- **多选**：手机上长按条目进入多选；电脑上悬停勾选，或按住 ⌘/Ctrl 点击。底部可以批量下载、移动、复制或移入回收站。
- **批量操作**会逐项提交，某一项结果不确定时停止后续操作，完成后列出每项的结果。

电脑上可以按 ⌘/Ctrl+F 打开搜索，按 Esc 退出多选或关闭搜索。

## 上传与下载

- 上传到个人文档库时，应用会先检查云端是否已有相同文件；有的话直接“秒传”，没有再完整上传。
- 下载单个文件时选择保存位置即可；下载文件夹或多个条目时会打包成 `.zip`。
- 列表上方显示传输进度，进行中可以“取消任务”。

提示“结果未确认”时，云端可能已经有结果。请先刷新目录核对，避免重复上传或覆盖。

## 分享

1. 在文件的“更多操作”中选“分享”。
2. 填写分享标题，设置是否需要提取码、有效期（永久有效、1 天、7 天、30 天或自定义）和访问次数。
3. 在“访问者可以”中选择在线预览、下载；文件夹分享还可以在“更多权限”中允许上传、修改。
4. 点“创建链接”，再点“复制分享链接”。

在“工具”→“分享管理”中可以查看全部分享，复制链接、“修改设置”或“取消分享”。取消后，已发出的链接会立即失效。

打开别人的分享：在“工具”中选“打开分享链接”，粘贴链接（可以直接粘贴含提取码的整段文字），按需填写提取码后点“打开”。进入后可以下载，或用“保存到我的网盘”另存。

分享链接可能让接收者访问相应文件，请只发给预期的接收者。

## 回收站

在“工具”→“回收站”中可以“恢复”或“永久删除”条目，只显示最近 100 项。永久删除的文件无法找回，请先确认不再需要。

## 注意事项

- 目前云盘按直连方式使用；通过 WebVPN 使用云盘（包括分享和文件传输）尚未完成验证。在校外无法打开时，不能把 WebVPN 登录成功当作云盘已经可用。
- 提示“云盘登录已失效”时，点“重新登录云盘”，完成后会回到原来的目录。
- UBAA 不提供全文检索、在线编辑或断点续传。
