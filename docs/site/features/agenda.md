# 日程与待办

“日程”把课程、考试、作业等学校安排和你自己添加的事项放在一起，本页介绍怎样查看、添加、导出和同步。

## 在哪里找到

- 点导航中的“日程”。
- 首页“待办”卡片显示近期截止与提醒，点“查看全部”进入日程。

## 查看

- **切换视图**：顶部选择“列表”“周”“月”。周和月视图用左右箭头翻页，离开当前时间段后点“回到今天”返回。
- **筛选**：点“筛选日程”，按事项来源（课程、作业、博雅、考试、研讨室、签到、阳光打卡、我的）筛选，也可以勾选“仅看待办”“显示已完成”“显示已隐藏”。“重置”恢复默认。宽屏上筛选常驻在左栏。
- **搜索**：点“搜索日程”，在当前时间范围内搜索标题、备注和地点。
- **详情**：点一项打开详情。学校事项可以点“查看原页面”跳到对应功能。

学校事项来自已经读取过的课表、考试和各类待办。显示“学校事项待刷新”时，在“更多日程操作”中选“刷新学校日程”。周视图只显示看过的几周课表，想看整学期可以选“导入整学期课表”。

## 整理学校事项

在学校事项的详情中可以：

- 点“标记完成”或“标记未完成”；
- 点“隐藏事项”，之后在筛选中勾选“显示已隐藏”可以找回并“恢复显示”；
- 点“添加备注…”，写完后“保存备注”。

这些调整只影响你自己的日程，不会修改学校记录。勾选完成不会替你提交作业、选课或预约。

## 添加自己的事项

1. 点右下角的加号按钮（新建事项），选择“日程”或“待办”。
2. 填写标题。日程填写开始和结束时间，可以勾选“全天”；待办填写截止时间，或勾选“无日期待办”。
3. 在“重复”中选择“不重复”“每天”“每周”“工作日”“按教学周”或“自定义”。
4. 按需填写地点、备注并选择颜色，点“保存事项”。

几点说明：

- 所有时间均为北京时间。
- “按教学周”需要填写第一教学周的周一日期、开始和结束教学周，并选择每周、单周或双周以及星期几。
- 重复事项可以填写“跳过日期 / 假期”，多个日期用逗号分隔。重复待办需要截止时间。
- 新事项与课程时间冲突时会提示，可以“返回修改”或“仍然保存”。

修改或删除重复事项时，会询问范围：“仅此次”“此次及以后”或“全部”。没有网络时也能编辑本机事项。

## 导出日历

1. 在“更多日程操作”中选“导出日历”。
2. 选择日期范围，再选“仅未完成事项”或“包含已完成事项”。
3. 把 `.ics` 文件保存到你选择的位置，导入其他日历应用。

导出文件是当时内容的快照，之后不会随 UBAA 自动更新。时间未定的事项不会导出。

## 北航云盘同步

开启后，你添加的日程、备注和完成状态会保存到个人北航云盘，换设备也能看到。

1. 在“更多日程操作”中选“数据与同步”。
2. 在“云端同步”中点“启用云端同步”，确认后开启。云盘里还没有日程时，按提示“创建云端日程”。
3. 之后修改会自动同步，也可以点“同步”立即同步。

同步默认关闭，数据保存在个人北航云盘的 `UBAA/agenda_snapshots` 目录。同步失败或显示“N 条修改未同步”时，本机内容不会丢失，稍后重试即可。通过 WebVPN 同步尚未完成验证，建议在可以直连时使用。

## 数据保存

- 日程单独保存在本机，清理缓存不会删除日程，“退出并清除本机数据”也会保留日程。
- 清除本机日程与删除云端内容是两回事，云盘中可能继续保留历史快照。
- 日程和云端快照不加密。不要在标题、备注或导出文件中保存密码等秘密。

详见[数据与隐私说明](/tech/data-and-privacy)。
