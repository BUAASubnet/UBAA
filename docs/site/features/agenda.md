# 日程与待办

“日程”把学校安排与自己添加的事项放在一起。首页显示近期预览，点击“查看全部”进入完整日程。

## 查看与整理

可以按日期、来源、事项类型和完成状态筛选，在日、周、月等视图中查看安排。学校事项来自已经获取的课表、考试和各类待办数据；刷新学校功能后，相应内容会更新。

学校事项可添加本机备注、隐藏或标记完成。这些调整只影响自己的日程展示，不修改学校记录，也不代替提交作业、选课或预约。

## 添加自己的事项

新增日程填写开始与结束时间，也可以添加全天事项、带截止时间的待办或无日期待办。重复事项支持常用重复规则、教学周和排除日期。

编辑或删除重复事项时，选择“仅此次”“此次及以后”或“全部”，确认修改范围后保存。没有网络时仍可编辑本机事项。

## 导出日历

使用“导出日历”选择日期范围，以及是否包含已完成事项，再把 `.ics` 文件保存到自己选择的位置。导出文件是当时内容的快照，导入其他日历应用后不会自动随 UBAA 更新。

## 北航云盘同步

在日程同步入口确认当前账号及连接路线后，可以启用同步。开启后，应用会在进入日程时拉取云端内容，并在本机修改后同步自己的事项、备注和完成状态。同步使用个人北航云盘中的 `UBAA/agenda_snapshots` 目录。

自动同步默认关闭。同步失败或提示结果待核对时，本机内容仍然保留，请查看状态并核对结果。当前完整 WebVPN 同步链路仍待验证。

## 数据保存

日程在设备上单独保存，普通业务缓存清理不会删除日程。清除本机日程与删除云端内容是不同操作；云盘可能继续保留历史快照。

日程及云端快照采用明文保存。请保护设备和云盘访问权限，不要在标题、备注或导出文件中保存密码等秘密。详情见[隐私政策](/tech/privacy-policy)与[状态与存储](/tech/state-storage)。
