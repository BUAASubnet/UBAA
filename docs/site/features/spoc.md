# SPOC 作业

本页介绍怎样查看 SPOC 平台的作业、截止时间和提交状态。

## 在哪里找到

导航“学习”→“SPOC作业”。首页“待办”也会列出临近截止的 SPOC 作业。

## 查看作业

1. 作业按课程分组，每项显示截止时间和提交状态（已提交 / 未提交）。
2. 默认只显示未提交、未截止的作业。
3. 点筛选按钮调整：
   - “排序方式”：按截止时间或按开始时间；“顺序”：升序或降序。
   - “范围”：取消“仅显示未提交”可以看到已提交的作业；打开“显示已截止”可以看到已过截止时间的作业。
4. 点作业打开“作业详情”，查看开始和截止时间、分值、提交时间与作业内容。

用搜索框可以按课程名称或作业标题查找。

## 注意事项

- UBAA 只提供查询，提交作业请到学校 SPOC 平台。
- 读取失败或登录失效时页面会显示错误，不能据此认为没有作业。

网络或登录问题见[常见问题](/tech/troubleshooting)。
