# SPOC 作业

本页介绍怎样查看 SPOC 作业、截止时间和提交状态，以及怎样观看课堂直播和回放。

## 在哪里找到

导航“学习”→“SPOC作业”。首页“待办”也会列出临近截止的 SPOC 作业。

## 查看作业

1. 作业按课程分组，每项显示截止时间和提交状态（已提交 / 未提交）。
2. 默认只显示未提交、未截止的作业。
3. 点筛选按钮调整：
   - “排序方式”：按截止时间或按开始时间；“顺序”：升序或降序。
   - “范围”：取消“仅显示未提交”可以看到已提交的作业；打开“显示已截止”可以看到已过截止时间的作业。
4. 点作业打开“作业详情”，查看开始和截止时间、分值、提交时间与作业内容。

用搜索框可以按课程名称或作业标题查找。

## 课堂直录播

在 SPOC 作业列表的课程标题行或作业详情页点“课堂”。同名课程对应多个课堂时，先选要查看的课堂。

直播中的节次置顶，其余节次按教学周分组。节次会显示“直播中”“回放”“无回放”“未开始”“腾讯会议”或“不可播放”。标为“腾讯会议”的节次需在腾讯会议中观看。

- **回放**：可以在教师和 PPT 画面之间切换，播放位置保持不变。支持倍速、拖动进度和全屏，点 PPT 缩略图或章节可以跳到对应位置。
- **逐字稿和摘要**：逐字稿随播放位置更新，可以搜索或点句跳转。摘要包含总结、关键词和问答。逐字稿和摘要由学校平台自动生成，可能不准确。
- **直播**：可以在教师和学生画面之间切换。

Android、iOS、macOS、Windows 和 Linux 支持应用内播放。Linux 需要安装系统的 libmpv，见[下载安装](/download#linux)。HarmonyOS 使用系统播放器，目前仅完成构建验证。所有平台都可以选择“用外部播放器打开”。

直连和 WebVPN 都可以读取课堂信息，视频直接从学校媒体服务器播放。UBAA 不签到、不上报观看进度、不发弹幕。如果显示“暂未在智学北航开通课堂”，说明学校尚未为这门课开通课堂。

## 注意事项

- UBAA 只提供查询，提交作业请到学校 SPOC 平台。
- 读取失败或登录失效时页面会显示错误，不能据此认为没有作业。

网络或登录问题见[常见问题](/tech/troubleshooting)。
