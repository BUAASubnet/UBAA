# 阳光打卡

本页介绍怎样查看阳光打卡进度、提交打卡和查看记录。

## 在哪里找到

导航“校园”→“阳光打卡”。

## 查看进度与记录

- 页面顶部显示“本学期认定次数”和“本周打卡”次数，有目标时会显示为“已完成 / 目标”。
- 打开“首页提醒”后，首页会提醒你本周的阳光打卡。
- 下方“打卡记录”列出每次打卡的项目、时间、地点、图片数量和是否分享，可以搜索，点“加载更多”查看更早的记录。

## 提交打卡

1. 点右下角的加号按钮（新增打卡）。
2. 在“填写阳光打卡信息”中按实际运动情况填写：
   - **运动项目**：点“选择运动项目”。
   - **时间**：同时填写开始时间和结束时间。
   - **地点**：填写实际运动地点。
   - **照片**：点“选择照片”，支持的设备上也可以“拍摄照片”，单张不超过 10 MB。
   - 按需勾选“分享到打卡广场”。
3. 点“提交打卡”。
4. 完成后到“打卡记录”确认已经登记。

## 注意事项

- 照片会发送到学校业务系统，只选择本次打卡需要的照片。
- 提交结果不确定时先刷新打卡记录，避免重复提交。
- 打卡认定以学校系统为准。

网络或登录问题见[常见问题](/tech/troubleshooting)。
