# 课堂签到

本页介绍怎样查看今日课程的签到状态并完成签到。

## 在哪里找到

- 导航“学习”→“课堂签到”。
- 首页“待办”中也会出现需要签到的课程，卡片上可以直接点“签到”。

## 签到步骤

1. 进入后查看今天的课程，每门课显示上课时间和签到状态。
2. 从上课前 10 分钟到下课前，课程旁会出现“签到”按钮，点击即可签到。
3. 还没到时间的课程显示“HH:MM 起可签”；已下课仍未签到的显示“未签到”；签到成功显示“已签到”。

点筛选按钮可以只看“可签到”或“已签到”的课程，搜索框可以按课程查找。

## 注意事项

- 签到前请遵守课堂要求。签到能否成功由学校系统决定。
- 状态显示不明确不等于未签到。签到失败或提示“结果未确认”时，先刷新查看，必要时向任课老师或学校系统核实，不要重复提交。
- 今天没有需要签到的课程时，页面会显示“今天没有需要签到的课程”。
