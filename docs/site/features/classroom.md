# 空教室查询

本页介绍怎样按日期、校区和教学楼查找空闲教室。

## 在哪里找到

导航“校园”→“空教室查询”。

## 查询步骤

1. 点右上角的校区按钮，在“学院路”“沙河”“杭州”之间切换。
2. 点日期标签，选择要查询的日期。
3. 点教学楼标签只看某栋楼。
4. 查看节次表格：每间教室按第 1–14 节显示是否空闲。查询当天时会标出当前节次。
5. 查询当天时，可以打开“此刻空闲”，只看当前节次空闲的教室。

搜索框可以按教学楼或教室名称查找。应用会记住你上次选择的校区和教学楼。

## 注意事项

空闲信息只反映课程占用情况，不保证教室开放，也不能代替学校的场地使用规定。

网络或登录问题见[排障指南](/tech/troubleshooting)。
