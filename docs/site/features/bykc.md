# 博雅课程

本页介绍怎样浏览博雅课程、选课退选、签到签退和查看达标情况。

## 在哪里找到

导航“学习”→“博雅课程”。页面顶部有三个分段：“选课”“已选”“统计”。

## 浏览与选课

1. 在“选课”中浏览课程，列表向下滚动会继续加载。
2. 用搜索框按课程、教师或地点查找；点筛选按钮可以按课程状态、课程类别和适用校区筛选。筛选只作用于已加载的课程。
3. 点课程打开“课程详情”，查看教师、地点、报名人数、类别，以及上课、选课和退选截止时间。
4. 点“选课”报名。名额已满时按钮显示“已满”。

## 退选

在课程详情中点“退选”，确认“退选这门课程？”后提交。退选后名额可能被他人选走，无法保证再次选上。超过退选截止时间后不能退选。

## 签到与签退

1. 在“已选”中打开课程。
2. 在“签到信息”中查看考勤和考核状态，点“查看签到与签退”了解签到时间与地点。
3. 在可签到的时间点“博雅签到”，课程结束时点“博雅签退”。

部分操作暂时不可用时，页面会提示“部分签到操作当前不可用”。

## 统计

“统计”显示各类课程的达标情况，例如“达标 3/5 类”。

## 注意事项

- 能否选课、退选、签到由学校的实时规则决定。截止时间已过、名额变化或报名条件不明确时，按钮可能不可用。
- 刷新时会保留已有列表和滚动位置。
- 提示“结果未确认”时，先刷新“已选”核对，不要重复提交。

网络或登录问题见[排障指南](/tech/troubleshooting)。
