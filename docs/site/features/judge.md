# 希冀作业

本页介绍怎样查看希冀平台的作业、题目完成情况和得分。

## 在哪里找到

导航“学习”→“希冀作业”。首页“待办”也会列出临近截止的希冀作业。

## 查看作业

1. 作业按课程分组，每项显示截止时间、完成状态（已提交 / 部分提交 / 未提交）和已交题数。
2. 默认只显示未完成、未截止的作业。
3. 点筛选按钮调整：
   - “排序方式”：按截止时间或按开始时间；“顺序”：升序或降序。
   - “范围”：取消“仅显示未完成”可以看到已完成的作业；打开“显示已截止”可以看到过期作业（此时会显示全部完成状态），再点“加载历史作业”读取更早的记录。
4. 点作业打开“作业详情”，查看提交信息、分数和“题目明细”（每题的状态与得分 / 满分）。

用搜索框可以按课程名称或作业标题查找。

## 注意事项

- UBAA 只提供查询，提交作业请到学校希冀平台。
- 读取失败或登录失效时页面会显示错误，不能据此认为没有作业。

网络或登录问题见[常见问题](/tech/troubleshooting)。
