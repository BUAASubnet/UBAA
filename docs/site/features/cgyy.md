# 研讨室预约

本页介绍怎样预约研讨室、管理预约和查看门锁密码。

## 在哪里找到

导航“校园”→“研讨室预约”。页面顶部有“预约”和“我的预约”两个分段，右侧的锁形按钮是“查看密码”。

## 预约研讨室

1. 在“预约”中选择日期，再按校区（全部、学院路、沙河）和楼层筛选。
2. 打开“只看可预约”可以隐藏不可用的时段；点“图例”查看格子颜色的含义。
3. 在时段表格中点选一个或多个可预约的格子，确认底部显示的已选时段后点“下一步”。
4. 在“填写预约信息”中填写联系电话、预约主题、活动类型、参与人数、活动内容和参与人说明；按实际情况勾选“哲学社会科学类活动”“含校外参与人”。
5. 点“提交预约”。

需要调整时段时点“返回修改时段”，填写的内容会保留。

## 管理预约

在“我的预约”中查看每条预约的地点、时间、主题和活动类型。点“查看详情”打开预约详情；需要取消时点“取消预约”，确认后提交。取消后时段可能被他人预约，无法恢复。

## 查看门锁密码

点锁形按钮“查看密码”。到了可开门的时段，页面会显示门锁密码、有效期和预约信息；未到时段时显示“未到开门时段”。需要更新时点“刷新密码”。

## 注意事项

- 预约和取消受学校规则和实时状态限制。
- 门锁密码只供本人预约使用，不要截图公开或在反馈中附上。
