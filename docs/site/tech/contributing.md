# 参与开发

本页写给想为 UBAA 贡献代码、文档或反馈的同学，告诉你从哪里开始。

UBAA 是开源项目，源码托管在 [GitHub](https://github.com/BUAASubnet/UBAA)。日常开发在 `dev` 分支进行，`main` 是发布分支，旧版代码保存在 [`ubaa1`](https://github.com/BUAASubnet/UBAA/tree/ubaa1) 分支。

## 从这里开始

- [项目首页（README）](https://github.com/BUAASubnet/UBAA/blob/main/README.md)：项目介绍、功能一览和技术栈。
- [贡献指南（CONTRIBUTING）](https://github.com/BUAASubnet/UBAA/blob/main/CONTRIBUTING.md)：从搭建开发环境到提交 Pull Request 的完整流程。
- [开发者文档](https://github.com/BUAASubnet/UBAA/blob/main/docs/README.md)：架构、公开合同、开发命令和运行手册。

## 不写代码也能帮忙

- 在 [GitHub Issues](https://github.com/BUAASubnet/UBAA/issues) 报告问题或提出建议，写法见[常见问题](/tech/troubleshooting#反馈问题)。
- 发现安全问题时，请使用 [GitHub 私有漏洞报告](https://github.com/BUAASubnet/UBAA/security/advisories/new)，不要公开发布。
- 本网站的页面源码在仓库的 `docs/site/` 目录，发现说明有误可以直接提交修改。
