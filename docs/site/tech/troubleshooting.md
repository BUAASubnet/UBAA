# 排障指南

## 无法登录或持续加载

先检查网络和连接方式。校外可选择 WebVPN；在具备校园访问条件的网络中可尝试直连。切换后核对已认证路线，必要时重新登录。

如果学校要求验证码，回到手动登录页完成验证。学校网页也不能登录时，应先处理账号或学校服务问题。

## 数据为空或看起来过旧

检查学期、日期、搜索和筛选条件，再刷新页面。离线缓存可能不是最新结果；读取失败也不能据此认定没有作业或预约。

## 操作后提示结果未确认

先查看预约、课程或打卡记录，并在必要时到学校系统核对。网络异常可能发生在学校已经接收请求之后，因此不要连续重复提交。

## 无法保存密码

检查系统安全存储是否可用。没有保存成功时可以按提示手动登录，不要把密码写入配置文件或公开日志。

## 反馈问题

在 [GitHub Issues](https://github.com/BUAASubnet/UBAA/issues) 说明应用版本、设备系统、连接方式、操作步骤和错误提示。可以参考设置中的本次运行诊断。

发送前删除个人资料、账号、Cookie、Token、验证码、预约门锁信息和包含个人数据的截图。
