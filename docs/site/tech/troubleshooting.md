# 常见问题

本页列出使用 UBAA 时的常见问题和处理办法。

## 无法登录或持续加载

1. 先确认网络正常，再检查连接方式：校外选“WebVPN”或“自动”；在校园网内可以试“直连”。
2. 切换后看设置页“连接模式”下方的“当前连接”，必要时退出后重新登录。
3. 登录失败时，登录页的错误提示下方有“查看诊断信息”，可以复制后用于反馈。

如果学校的统一认证网页本身也无法登录，请先处理账号或学校服务的问题。

## 要求输入验证码

应用会先自动识别学校的图片验证码。识别不成功时会弹出“登录验证”，输入图片中的字符后点“验证”。看不清就点图片刷新；点“取消”后需要重新登录。

## 标题栏出现连接提示

标题栏右上角出现连接状态按钮时，点开可以看到当前问题并“重试”。如果按钮提示“完成登录”，说明某种连接方式需要你重新验证，点开按提示完成即可。

网络超时和登录过期是两类问题：先检查网络和连接方式，确认是登录过期后再重新登录。

## 数据为空或看起来过旧

- 检查学期、日期、搜索词和筛选条件。筛选生效时，筛选按钮会显示生效的条件数。
- 手机和平板下拉页面刷新；电脑点标题栏右上角的“刷新”。标题栏的“更新于”显示内容的更新时间。
- 离线时显示的是上次保存的内容，可能不是最新结果。
- 读取失败不代表没有作业、考试或预约，请刷新后再判断。

## 操作后提示结果未确认

“结果未确认”表示提交时网络中断，学校可能已经收到，也可能没有。

1. 到对应页面（如“我的预约”“已选”、打卡记录）刷新查看，必要时到学校系统核对。
2. 不要连续重复提交。
3. 首页会显示“N 项操作需要你确认结果”，点“去查看”核对；确认后点“已确认，关闭提醒”。关闭提醒不会改变学校记录。

## 无法保存密码

“记住密码”依赖系统安全存储。不可用时登录页会提示“密码只在本次运行中使用”，此时每次手动登录即可。不要把密码写进配置文件或公开日志。

Linux 桌面需要当前用户已解锁的 Secret Service（如 GNOME 钥匙环）；通过 SSH 登录、没有可用安全存储时，命令模式会说明原因。

## 存储空间不足

页面提示“手机存储空间不足，本次内容未能保存”时，已显示的内容不受影响。清理设备空间后再刷新，或在设置中[清理缓存](/tech/configuration#数据与隐私)。

## 反馈问题

在 [GitHub Issues](https://github.com/BUAASubnet/UBAA/issues) 说明应用版本（“关于”页可查看）、设备系统、连接方式、操作步骤和错误提示。设置中的“诊断信息”可以复制附上。

发送前删除个人资料、账号、Cookie、Token、验证码、研讨室门锁密码和包含个人数据的截图。发现安全漏洞请使用 [GitHub 私有漏洞报告](https://github.com/BUAASubnet/UBAA/security/advisories/new)。
