# 设置说明

本页介绍 UBAA 设置页里的每一项，帮你调整外观、连接方式、缓存、统计和账号。

## 打开设置

- 手机：底部导航进入“我的”，点“设置”。
- 平板和电脑：点侧栏底部的“设置”（齿轮图标）。

设置页分为“个性化”“连接模式”“数据与隐私”“账号”四组。

## 个性化

“外观主题”可选“跟随系统”“浅色”“深色”。

- 选择保存在本机，重启后恢复，退出登录或清除账号不会重置它。
- 第一次使用或读取失败时跟随系统。
- 如果保存失败，本次选择仍然生效，但下次启动可能恢复为跟随系统。

## 连接模式

可选“自动”“直连”“WebVPN”，点选即切换。已经连上时，下方会显示“当前连接：直连”或“当前连接：WebVPN”。怎么选见[登录与连接方式](/features/auth-and-connection)。

## 数据与隐私

| 条目 | 作用 |
| --- | --- |
| 本机缓存 | 显示缓存占用空间；“清理缓存”清除本机保存的课表、学校待办、查询内容和未确认的提交提醒 |
| 产品改进统计 | 默认开启，可以随时关闭。按天汇总功能使用、错误类别和加载耗时，另按分钟汇总登录与功能加载次数，不含密码、成绩、课表等内容，详见[隐私政策](/tech/privacy-policy#产品改进统计) |
| 诊断信息 | 查看本次运行的错误记录，可复制后用于反馈问题 |

- 清理缓存会保留登录状态、账号和本机日程。查询内容之后可以重新获取，但未确认的提交提醒清除后无法恢复。正在提交操作时，清理按钮暂时不可用。
- 关闭“产品改进统计”会停止收集和上传，并清空设备上尚未上传完成的统计。已上传的数据按[隐私政策](/tech/privacy-policy)的期限保留，需要删除时可以联系维护者。
- 检查新版本和接收公告不受统计开关影响。

各类数据保存在哪里、清除后还剩什么，见[数据与隐私说明](/tech/data-and-privacy)。

## 账号

- **退出登录**：回到登录页。
- **退出并清除本机数据**：退出登录，并清除保存的密码和已保存的学校数据。本机日程会保留，学校服务器上的数据不会被删除。

手机上“我的”页底部也有“退出登录”。各操作的完整清除范围见[怎样清除](/tech/data-and-privacy#怎样清除)。

登录页的“记住密码”“自动登录”见[登录与连接方式](/features/auth-and-connection#登录)，桌面命令的资料目录见[桌面命令模式](/features/command#资料目录)。
