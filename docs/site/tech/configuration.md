# 设置说明

本页介绍 UBAA 设置页里的每一项，帮你调整外观、连接方式、缓存和账号。

## 打开设置

- 手机：底部导航进入“我的”，点“设置”。
- 平板和电脑：点侧栏底部的“设置”（齿轮图标）。

设置页分为“个性化”“连接模式”“数据与隐私”“账号”四组。

## 个性化

“外观主题”可选“跟随系统”“浅色”“深色”。

- 选择保存在本机，重启后恢复，退出登录或清除账号不会重置它。
- 第一次使用或读取失败时跟随系统。
- 如果保存失败，本次选择仍然生效，但下次启动可能恢复为跟随系统。

## 连接模式

可选“自动”“直连”“WebVPN”，点选即切换。已经连上时，下方会显示“当前连接：直连”或“当前连接：WebVPN”。怎么选见[登录与连接方式](/features/auth-and-connection)。

## 数据与隐私

| 条目 | 作用 |
| --- | --- |
| 本机缓存 | 显示缓存占用空间；“清理缓存”清除本机保存的课表、学校待办、查询内容和未确认的提交提醒 |
| 隐私政策 | 查看、同意或撤回[隐私政策](/tech/privacy-policy)。不同意时为基础模式：不检查更新、不接收公告、不上传统计，学校功能照常可用 |
| 产品改进统计 | 同意隐私政策后可开关。按天汇总功能使用、错误类别和加载耗时，不含密码、成绩、课表等内容 |
| 删除已上传的统计数据 | 请求服务器删除本机已上传的统计明细；暂时连不上时会稍后自动重试 |
| 诊断信息 | 查看本次运行的错误记录，可复制后用于反馈问题 |

清理缓存会保留登录状态、账号和本机日程。查询内容之后可以重新获取，但未确认的提交提醒清除后无法恢复。正在提交操作时，清理按钮暂时不可用。

各类数据保存在哪里、清除后还剩什么，见[数据与隐私说明](/tech/data-and-privacy)。

## 账号

- **退出登录**：回到登录页。
- **退出并清除本机数据**：退出登录，同时清除保存的密码、已保存的学校数据、成绩变化记录及提醒设置。本机日程和账号关联会保留，学校服务器上的数据不会被删除。

手机上“我的”页底部也有“退出登录”。

## 登录页选项

登录页提供“记住密码”和“自动登录”两个选项。它们依赖设备的系统安全存储；当前平台没有可用的安全存储时，选项不可勾选，页面会提示“密码只在本次运行中使用”。

## 桌面命令

桌面 `ubaa-cli` 命令与图形界面共用账号和本机数据，也可以用 `--config-dir` 指定另一个资料目录。系统安全存储里的账号材料仍属于当前系统用户，单独换目录不等于隔离全部账号材料。

```bash
ubaa-cli --help
ubaa-cli auth login --username YOUR_USERNAME
ubaa-cli auth status
```

密码通过不回显的输入或标准输入提供，不写在命令参数里。安装与用法见[桌面命令模式](/features/command)。
