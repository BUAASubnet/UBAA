# 状态与存储

## 本地数据

应用使用本地配置、路线会话、账号安全材料和业务缓存。直连与 WebVPN 会话分别管理，普通页面只能看到公开的数据投影。

保存密码依赖平台安全存储。业务缓存使用加密存储，并区分账号与数据种类。已有缓存可以用于离线阅读，但过期或离线数据不会赋予提交资格。

自建日程、备注和完成标记保存于独立的明文数据库，桌面命令与图形界面共用。开启日程同步后，个人北航云盘会保存明文快照。日程和导出文件不适合保存密码等秘密。

## 清理

设置中提供业务缓存清理。退出登录与清除已保存账号有不同效果，请按页面提示选择。正在提交时，部分清理操作可能暂时不可用。

业务缓存清理保留日程。显式清除本机日程不会自动删除云盘中的历史快照，云端内容需要单独管理。

不要通过删除密钥、手改会话文件或复制其他账号缓存来修复登录问题。需要排障时先查看[排障指南](/tech/troubleshooting)。
