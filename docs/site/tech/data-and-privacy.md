# 数据与隐私说明

本页说明 UBAA 在你的设备上保存哪些数据、请求发往哪里，以及怎样清除。正式条款以[隐私政策](/tech/privacy-policy)为准。

## 请求发往哪里

- 课表、成绩、预约等校园请求由你的设备直接发往学校系统或学校 WebVPN，不经过 UBAA 的服务器中转。
- 同意隐私政策后，应用会联网检查更新、获取公告，并在开启时上传产品改进统计。不同意也能正常使用学校功能。
- 本网站是独立的静态网站，不提供校园登录，也不接收学校账号、密码或校园业务请求。

## 设备上保存了什么

| 数据 | 保存方式 | 说明 |
| --- | --- | --- |
| 记住的密码 | 系统安全存储（如钥匙串） | 只在勾选“记住密码”后保存 |
| 登录状态 | 本机 | 用于恢复登录；直连和 WebVPN 各自保存 |
| 学校数据缓存 | 加密保存，按账号区分 | 课表、成绩、待办等，用于再次打开和离线查看 |
| 自建日程、备注、完成标记 | 本机明文数据库 | 桌面命令与图形界面共用 |
| 日程云端快照 | 个人北航云盘，明文 | 只在开启日程云端同步后生成 |
| 外观主题等偏好 | 本机普通偏好 | 不含账号信息 |
| 诊断信息 | 仅本次运行的内存 | 不会自动上传 |

日程和云端快照不加密。不要在日程标题、备注或导出的日历文件中保存密码等秘密。

离线显示的缓存只用于查看。选课、预约、签到等操作必须联网，由学校系统确认。

## 怎样清除

| 操作 | 位置 | 清除的内容 | 保留的内容 |
| --- | --- | --- | --- |
| 清理缓存 | 设置 → 数据与隐私 → 本机缓存 | 课表、学校待办、查询内容、未确认的提交提醒 | 登录状态、账号、本机日程 |
| 退出登录 | 设置 → 账号 | 当前登录 | — |
| 退出并清除本机数据 | 设置 → 账号 | 保存的密码、已保存的学校数据、成绩变化记录、提醒设置 | 本机日程、账号关联 |
| 删除已上传的统计数据 | 设置 → 数据与隐私 | 服务器上本机已上传的统计明细 | 不含任何标识的整体汇总数字 |

清除本机日程不会自动删除北航云盘里的日程快照，云端内容需要到[北航云盘](/features/bhpan)中单独管理。学校服务器上的数据不受以上任何操作影响。

遇到登录问题时，不要删除系统密钥、手动修改登录状态文件或复制其他账号的缓存，先看[常见问题](/tech/troubleshooting)。
