# 更新日志

## UBAA v2.0 开发版本

- 核心协议实现迁移到 Rust，界面迁移到 Flutter。
- 支持直连、WebVPN 和自动路线选择，移除旧版服务器中转依赖。
- 提供课表、考试、成绩、空教室、SPOC、希冀、博雅、图书馆、研讨室、课堂签到、阳光打卡、评教与 iHome 功能。
- 增加本地加密缓存、离线查看与提交结果核对。
- 使用 VitePress 维护新版说明，并准备通过 GitHub Pages 发布文档站。

以上描述开发分支的能力，不指定正式发布日期。安装包、平台支持与每次正式版本的变更以 [GitHub Releases](https://github.com/BUAASubnet/UBAA/releases) 为准。
