# 更新日志

本页按版本列出 UBAA 的新增功能、体验改进和升级注意事项。

## v2.0.0

2026-11-14 起提供 Android、Windows、macOS 和 Linux 安装包下载，iOS 与 HarmonyOS 版本将通过应用商店提供。安装包见[下载 UBAA](/download)。

UBAA v2.0.0 重建了客户端，保留校园查询和办理功能，增加日程、云盘及桌面命令等能力。完整的新旧对照见[UBAA v2.0 新变化](/guide/ubaa2)。

### 新增功能

- 独立日程与待办：自建事项、重复规则、教学周、学校事项备注与完成标记、`.ics` 导出和可选的北航云盘同步。
- 北航云盘：文件浏览与管理、上传下载、分享、回收站与传输状态。
- 财务收入查询：按年份读取、明细搜索和月份小计。
- 桌面命令模式：终端与图形界面共用账号、缓存和日程，支持 JSON 输出。
- 新增 HarmonyOS 版本，与 Android、iOS、Windows、macOS 和 Linux 共用主要功能。

### 使用体验

- 增加“自动”连接方式，直连与 WebVPN 分别保持登录，网络变化后自动恢复需要的连接。
- 学校数据统一加密缓存，先显示已有内容，再更新在线结果。
- 首页预览近期安排，日程支持筛选与不同时间视图；手机、平板和桌面使用对应布局。
- 博雅课程按需加载，同范围刷新保留已有列表与滚动位置，退选操作按学校截止时间判断。
- 研究生课表采用学校当前学期标记，成绩支持历史和分学期统计。
- 增加新版本提示和公告。产品改进统计默认开启，可以在设置中关闭，详见[数据与隐私说明](/tech/data-and-privacy)。

### 升级注意

首次使用需要重新登录，旧版的登录状态、密码和偏好不会迁移。各平台的升级方式见[从 v1.x 升级](/guide/ubaa2#upgrade)，已知限制见[当前限制](/guide/ubaa2#当前限制)。
