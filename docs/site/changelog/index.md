# 更新日志

## v2.0.0（待发布）

UBAA v2.0.0 使用 Flutter 与 Rust 重建客户端，保留校园查询和办理功能，增加日程、云盘及桌面命令等能力。完整的新旧对照见[UBAA v2.0 新变化](/guide/ubaa2)。

### 新增功能

- 独立日程与待办：自建事项、重复规则、教学周、学校事项备注与完成标记、`.ics` 导出和可选的北航云盘同步。
- 北航云盘：文件浏览与管理、上传下载、分享、回收站与传输状态。
- 财务收入查询：按年份读取、明细搜索和月份小计。
- 桌面命令模式：终端与图形界面共用账号、缓存和日程，支持 JSON 输出。
- HarmonyOS 应用工程，与 Android、iOS、Windows、macOS 和 Linux 共用主要功能。

### 使用体验

- 增加“自动”连接方式，直连与 WebVPN 分别保持登录，网络变化后自动恢复需要的连接。
- 学校数据统一加密缓存，先显示已有内容，再更新在线结果。
- 首页预览近期安排，日程支持筛选与不同时间视图；手机、平板和桌面使用对应布局。
- 博雅课程按需加载，同范围刷新保留已有列表与滚动位置，退选操作按学校截止时间判断。
- 研究生课表采用学校当前学期标记，成绩支持历史和分学期统计。
- 接入隐私选择、可选使用统计、版本检查和公告；服务可用性取决于发行包的渠道配置。

### 升级与适用范围

首次使用准备好重新登录。当前没有旧版登录状态、密码和偏好的自动迁移承诺，覆盖安装条件与实际分发平台将在正式发布说明中列出。

研究生考试明细、通过 WebVPN 使用云盘以及各平台的安装范围见[当前限制](/guide/ubaa2#当前限制)。自建日程和云端快照采用明文保存。

当前可下载的安装包与商店分发情况见[下载页](/download)。正式发布记录以 [GitHub Releases](https://github.com/BUAASubnet/UBAA/releases) 为准。
