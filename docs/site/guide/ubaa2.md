# UBAA v2.0 新变化

本页帮用过旧版的同学了解 v2.0 新增了什么、怎样从 v1.x 升级，以及目前还有哪些限制。

UBAA v2.0 保留了旧版常用的校园查询与办理功能，重点增加了日程、北航云盘、财务查询和桌面命令模式，并重新设计了连接恢复、离线查看与跨平台界面。旧版源码归档在 [UBAA v1.x](https://github.com/BUAASubnet/UBAA/tree/ubaa1)。

## 主要变化

手机上可以横向滑动表格查看。

<div class="upgrade-comparison">

| 方面 | 旧版 UBAA v1.x | UBAA v2.0 |
| --- | --- | --- |
| 日程安排 | 首页聚合学校待办，各功能分别查看 | 增加独立日程页，合并学校安排与自建日程、待办，支持重复规则、教学周和日历导出 |
| 北航云盘 | 应用内没有独立文件管理页面 | 浏览文档库、管理文件、上传下载、分享与回收站，并用于可选的日程同步 |
| 财务查询 | 应用内没有财务收入入口 | 按年份查询收入记录，搜索明细并查看月份小计 |
| 连接方式 | 手动选择直连或 WebVPN，切换时清除登录状态 | 增加“自动”，直连和 WebVPN 分别保持登录，网络变化后自动恢复可用的连接 |
| 离线使用 | 部分功能保存偏好和短期缓存 | 统一保存学校数据缓存，页面先显示已有内容，再更新在线结果；本机日程可离线编辑 |
| 桌面使用 | 通过图形界面操作 | 同时提供图形界面与 `ubaa-cli` 命令，共用账号、缓存和日程 |
| 平台与界面 | 手机和桌面 | 支持 Android、iOS、HarmonyOS、Windows、macOS 和 Linux，手机、平板和电脑使用统一的功能界面 |

</div>

## 学校安排与自己的计划放在一起

在“日程”中查看学校安排，并添加讨论、活动、复习计划或无截止时间的待办。重复事项可以按每周、单双教学周等规则安排，修改时可以选择仅此次、此次及以后或整个系列。

学校事项支持本机备注、隐藏和完成标记。例如，可以在作业旁边记下自己的提醒，但在日程中勾选完成不会替你向学校提交作业。首页提供近期事项预览，完整内容可以在日程中筛选查看。

日程可以导出为 `.ics` 文件，供其他日历应用导入。需要换设备使用时，可以主动开启北航云盘同步。操作说明见[日程与待办](/features/agenda)。

## 增加云盘和财务入口

[北航云盘](/features/bhpan)集中提供目录浏览、文件管理、上传下载、分享与回收站。文件传输有独立状态，结果尚未确认时会提示核对，避免把上传中断当作已经完成。

[财务查询](/features/finance)提供收入记录、月份小计和明细搜索。页面展示学校财务系统的记录，银行实际到账需另行核对。

## 网络变化时继续查看已有内容

“自动”会根据网络情况准备直连和 WebVPN。普通查询优先直连，遇到网络不通或超时时，再改用 WebVPN。手动固定直连或 WebVPN 仍然保留，设置页的“当前连接”和标题栏的连接提示可以帮助判断当前可用的连接。详见[登录与连接方式](/features/auth-and-connection)。

页面已有缓存时先显示缓存，刷新成功后再更新。离线内容只用于查看，选课、预约等操作仍需联网，由学校系统确认。

## 桌面增加命令模式

桌面安装包附带 `ubaa-cli` 命令，可以在终端查看课表、成绩和云盘，查询、修改或导出本机日程。命令模式与图形界面使用同一份账号和本机数据，适合脚本调用和批量整理。

命令同时提供可读文本与 JSON 输出。使用方法见[桌面命令模式](/features/command)。

## 从 v1.x 升级 {#upgrade}

所有平台都需要注意：

- 首次打开新版需要重新登录。旧版的登录状态、密码和偏好不会迁移。
- 需要保留的内容（例如旧版里的个人设置），先在旧版中记下或备份。

各平台的升级方式：

| 平台 | 怎样升级 |
| --- | --- |
| Android | 新版沿用旧版的应用标识和签名，直接安装新版 APK 即可覆盖升级 |
| Windows、macOS、Linux | 新版安装包与旧版不同。装好新版后，如果旧版仍在，确认不再需要后自行卸载 |
| iOS、HarmonyOS | 新版上架后通过应用商店更新 |

安装包见[下载 UBAA](/download)。

## 当前限制

- UBAA v2.0 没有网页版，旧版的网页版不再提供。
- iOS 与 HarmonyOS 版本还在等待应用商店上架。
- 通过 WebVPN 使用北航云盘和日程同步尚未完成验证；日程同步默认关闭，需要主动开启。
- 研究生课表与成绩已接入，研究生非空考试明细目前会提示暂不支持，不能据此判断没有考试。
- 学校数据缓存加密保存；自建日程和云盘同步快照为明文，请勿在日程备注中保存密码等秘密，详见[数据与隐私说明](/tech/data-and-privacy)。

各版本的具体变化见[更新日志](/changelog/)。
