# UBAA v2.0 相比旧版升级了什么

UBAA v2.0 保留了旧版常用的校园查询与办理功能，重点增加了日程、北航云盘、财务查询和桌面命令模式，并重新设计了连接恢复、离线查看与跨平台界面。

本文对照归档的 [UBAA v1.x](https://github.com/BUAASubnet/UBAA/tree/ubaa1) 与 UBAA v2.0。安装包和平台分发情况见 [GitHub Releases](https://github.com/BUAASubnet/UBAA/releases)。

## 主要变化

手机上可以横向滑动表格查看。

| 平台与界面 | Kotlin 与 Compose，原生目标包括手机和桌面 | Flutter 与 Rust，增加 HarmonyOS 工程，并统一手机、平板和桌面的功能界面 |

## 学校安排与自己的计划放在一起

在“日程”中查看学校安排，并添加讨论、活动、复习计划或无截止时间的待办。重复事项可以按每周、单双教学周等规则安排，修改时可以选择仅此次、此次及以后或整个系列。

学校事项支持本机备注、隐藏和完成标记。例如，可以在作业旁边记下自己的提醒，但在日程中勾选完成不会替你向学校提交作业。首页提供近期事项预览，完整内容可以在日程中筛选查看。

日程可以导出为 `.ics` 文件，供其他日历应用导入。需要换设备使用时，可以主动开启北航云盘同步。操作说明见[日程与待办](/features/agenda)。

## 增加云盘和财务入口

[北航云盘](/features/bhpan)集中提供目录浏览、文件管理、上传下载、分享与回收站。文件传输有独立状态，结果尚未确认时会提示核对，避免把上传中断当作已经完成。

[财务查询](/features/finance)提供收入记录、月份小计和明细搜索。页面展示学校财务系统的记录，银行实际到账需另行核对。

## 网络变化时继续查看已有内容

“自动”会根据网络情况准备直连和 WebVPN。普通查询优先直连，遇到网络不通或超时时，再改用 WebVPN。手动固定直连或 WebVPN 仍然保留，设置页的“当前连接”和标题栏的连接提示可以帮助判断当前可用的连接。详见[登录与连接方式](/features/auth-and-connection)。

页面已有缓存时先显示缓存，刷新成功后再更新。博雅课程按需加载，同范围刷新期间保留已有列表与滚动位置。离线内容只用于查看，选课、预约等操作仍需联网，由学校系统确认。

## 桌面增加命令模式

安装包含命令组件的桌面应用后，可以在终端查看课表、成绩和云盘，查询、修改或导出本机日程。命令模式与图形界面使用同一份账号和本机数据，适合脚本调用和批量整理。

命令同时提供可读文本与 JSON 输出。安装方法、示例和操作确认方式见[桌面命令模式](/features/command)。

## 从旧版升级

按照[安装与首次登录](/guide/start)选择正式发布的 UBAA v2.0 安装包。首次使用准备好重新登录，旧版的登录状态、密码和偏好不会自动迁移。需要保留的内容先按原应用支持的方式备份。

本次发布版本为 v2.0.0。最低系统要求、覆盖安装条件与可安装的平台以发布说明为准。

## 当前限制

- UBAA v2.0 没有网页版，旧版的网页版不再提供。
- HarmonyOS 等平台能否正式安装，以对应发布说明为准。
- 通过 WebVPN 使用北航云盘和日程同步尚未完成验证；日程同步默认关闭，需要主动开启。
- 研究生课表与成绩已接入，研究生非空考试明细目前会提示暂不支持，不能据此判断没有考试。
- 学校数据缓存加密保存；自建日程和云盘同步快照为明文，请勿在日程备注中保存密码等秘密，详见[数据与隐私说明](/tech/data-and-privacy)。

各版本的具体变化见[更新日志](/changelog/)。
