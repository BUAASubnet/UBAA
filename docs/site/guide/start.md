# 安装与首次登录

## 获取应用

从 [GitHub Releases](https://github.com/BUAASubnet/UBAA/releases) 查看发布说明，选择明确标注为 UBAA v2.0 且适合设备的安装包。如果列表中没有对应版本或平台，请等待发布，不要将旧版包或开发构建当作正式版本。

新版工程面向 Android、iOS、Windows、macOS、Linux 和 HarmonyOS。各平台安装条件、签名与分发方式以对应发布说明为准。UBAA v2.0 当前没有浏览器版校园服务入口。

## 首次登录

1. 打开应用，输入学校账号与密码。
2. 根据当前网络选择自动、直连或 WebVPN。校外通常使用 WebVPN。
3. 如果登录页要求验证码，按页面提示完成验证。验证码失效时刷新后再输入。
4. 登录后查看个人资料与所需功能。如果某条连接路线未就绪，按提示重新登录或选择已经就绪的路线。

需要保存密码时，使用登录页提供的记住密码选项。保存能力依赖设备安全存储；不支持或存储失败时按提示处理。

## 日常使用

从首页和功能入口打开课表、作业、预约等页面。手机与宽屏设备的导航布局不同，功能按名称查找即可。列表有搜索或筛选入口时，可以缩小查询范围。

已有缓存可能先于网络结果显示。重要的成绩、截止时间和预约状态应刷新后核对。提交操作后，如果提示结果未确认，请先到记录页或学校系统查看，避免重复提交。

## 从旧版切换

请保留仍需使用的旧版数据，按照新版发布说明安装并重新登录。当前文档不承诺自动迁移旧版登录状态、密码或本地偏好。

遇到问题可查看[连接方式](/features/auth-and-connection)和[排障指南](/tech/troubleshooting)。
