# 安装与首次登录

本页帮你下载 UBAA、完成第一次登录，并了解日常使用的基本方式。

## 获取应用

从 [GitHub Releases](https://github.com/BUAASubnet/UBAA/releases) 查看发布说明，选择 UBAA v2.0.0 或后续版本中适合设备的安装包。当前 2.0.0 正在准备发布，如果列表中没有对应版本或平台，请等待发布。

新版面向 Android、iOS、Windows、macOS、Linux 和 HarmonyOS。各平台的安装条件和分发方式以对应发布说明为准。UBAA v2.0 没有网页版。

## 首次登录

1. 打开应用，输入学号与密码。
2. 按需勾选“记住密码”和“自动登录”，点“登录”。这两项依赖设备的系统安全存储，不支持时不可勾选。
3. 学校要求验证码时，应用会先自动识别；识别不成功会弹出“登录验证”，输入图片中的字符即可，看不清就点图片刷新。
4. 连接方式默认是“自动”，一般不用改。需要固定时，在设置的“连接模式”中选择“直连”或“WebVPN”。

详见[登录与连接方式](/features/auth-and-connection)。

## 日常使用

- 手机底部导航有“首页”“学习”“日程”“校园”“我的”；平板和电脑使用左侧侧栏。
- “学习”里是课表、签到、作业、博雅、考试、成绩和评教；“校园”里是 iHome、云盘、财务、空教室、图书馆、研讨室和阳光打卡。
- “日程”汇集学校安排与自建事项。

全部功能见[功能总览](/features/)。

打开页面时可能先显示上次保存的内容，再更新为最新结果。重要的成绩、截止时间和预约状态请刷新后核对。提交后如果提示结果未确认，请先到记录页或学校系统查看，避免重复提交。

## 从旧版切换

先阅读[新版升级了什么](/guide/ubaa2)，保留仍需使用的旧版数据，按照新版发布说明安装并重新登录。旧版的登录状态、密码和本地偏好不会自动迁移。是否支持直接覆盖安装，以对应平台发布说明为准。

遇到问题可查看[登录与连接方式](/features/auth-and-connection)和[排障指南](/tech/troubleshooting)。
