# 安装与首次登录

本页帮你装好 UBAA、完成第一次登录，并认识应用里的主要页面。

## 获取应用

前往[下载 UBAA](/download)，按设备选择安装包。Android、Windows、macOS 和 Linux 可以直接下载；iOS 与 HarmonyOS 版本将通过应用商店提供。UBAA v2.0 没有网页版。

用过旧版 v1.x？先看[从 v1.x 升级](/guide/ubaa2#upgrade)。

## 首次登录

1. 打开应用，输入学号与密码。
2. 按需勾选“记住密码”和“自动登录”，点“登录”。
3. 学校要求验证码时，应用会先自动识别；识别不成功会弹出“登录验证”，输入图片中的字符即可。

连接方式默认是“自动”，一般不用改。验证码、连接方式和登录失败的处理见[登录与连接方式](/features/auth-and-connection)。

## 认识主要页面

- 手机底部导航有“首页”“学习”“日程”“校园”“我的”；平板和电脑使用左侧侧栏。
- “学习”里是课表、签到、作业、博雅、考试、成绩和评教；“校园”里是 iHome、云盘、财务、空教室、图书馆、研讨室和阳光打卡。
- “日程”汇集学校安排与自建事项。

全部功能见[功能总览](/features/)。

## 使用时请留意

- 打开页面时可能先显示上次保存的内容，再更新为最新结果。重要的成绩、截止时间和预约状态请刷新后核对。
- 提交后如果提示“结果未确认”，先到记录页或学校系统查看，不要重复提交，详见[常见问题](/tech/troubleshooting#操作后提示结果未确认)。
