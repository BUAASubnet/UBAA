# 文档归档

本目录保存已被取代的目标、计划、状态快照、审查记录和验收证据，只用于追溯“当时为什么这样做”。现行规则和现状请看[开发者文档首页](../README.md)。

阅读归档时请注意：

- 文中的“当前”“待完成”、测试计数、源码路径和任务授权，都只代表记录当时的情况。
- 归档文件保持原文，内部链接按原位置编写，可能已经失效。断链检查不覆盖本目录。需要还原当时的上下文时，用 `git log --follow -- <文件>` 找到原提交，查看那时的文件树。
- 历史材料不能作为当前任务的授权，也不能代替当前的验证结果。

| design/ | 已完成的设计实施计划和交付清单 |
