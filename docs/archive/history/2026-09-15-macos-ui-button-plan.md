### Task 1: 冻结旧版与当前按钮接线审计

仅静态读取旧版和当前共享 UI/Host/App/Bridge，列出全部页面的按钮、功能、条件、结果与可证实缺口，沿已有84项稳定编号记录。重点查找空回调、无效控件、错查询、未投影字段、默认选择、详情/返回、平台功能。报告写入 `docs/design/macos-ui-source-audit.md`；不改生产代码，不读取凭据、不调用实时上游、不控制 App。生产修复前补齐适用双来源对照。

### Task 2: 真实 macOS 逐按钮操作

用 computer use 在独立配置的生产 App 登录，依次操作登录/全局、学业、课程作业、博雅、图书馆、研讨室、阳光、签到/评教和设置。逐按钮记录实际结果，所有列表、详情、筛选、分页、返回、刷新、表单、取消均纳入，按[操作检查点](macos-ui-button-checklist.md)逐项回填证据。无真实记录/资格的分支标注并用显式合成 backend 在同一生产组件中验证，不能把合成结果写成真实上游通过。

### Task 3: 行为修复与复测

按复现结果分批记录来源，增加有意义的失败行为测试，观察失败后最小修复；聚焦测试、敏感检查与 `just check` 通过后阶段提交。每批独立审查并在 macOS computer use 复测。后台返回、查询条件和取消不得丢上下文；写操作保持单次提交和未知结果保护。

### Task 4: 完整门禁与交付

运行 `just refs`、`just layout-check`、`just check-sensitive`、`just check`（含CLI端到端）、`just flutter-check`，以及 Direct/WebVPN `just verify-live`。核对每个清单条目已有充分且适用证据，完成分支审查、更新状态/决策/合同并整合到当前项目。真实上游不可用保留具体失败，不伪称全部可用。
