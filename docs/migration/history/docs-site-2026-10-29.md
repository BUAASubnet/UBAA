# UBAA v2.0 文档站迁移记录

## 范围

将旧 `main` 的 VitePress 导航与页面结构迁到 `ubaa2`，网站名称保持 UBAA，版本标记使用 v2.0。网站源码在 `docs/site/`，共 31 篇 Markdown，包含入门、各功能、技术说明、隐私、公告与版本说明。旧版使用文档不另行归档，旧审计材料和二维码不复制到网站。

旧站来源是本地 `main` 的 `.github/workflows/docs.yml`、`docs/.vitepress/config.mts` 与相关正文。新版内容依据现有 README、公开合同、迁移矩阵，以及登录、设置、iHome、作业和缓存的生产代码。没有改动应用协议或真实学校状态。

## 部署方式

VitePress 固定为 `2.0.0-alpha.21`，锁文件使用 npm 公共仓库。GitHub Actions 的构建与发布分开：PR 始终只构建，push 在 `ubaa2/main/dev` 检查，部署分支由 `DOCS_PUBLISH_BRANCH` 指定。Pages 配置返回基础路径，支持根域名与 `/UBAA/` 项目路径。

发布手册见[网站维护](../../runbooks/docs-site.md)。本轮没有推送、启用 Pages、修改 DNS、删除旧服务器文件或创建正式 Release。
