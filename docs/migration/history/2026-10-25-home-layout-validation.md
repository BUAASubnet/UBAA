# 首页布局历史实现与验证

以下为 2026-10-25 的实现、测试和原生验收记录，旧测试路径只描述当时入口。当前状态见[状态页](../status.md)。

## 失败反例与覆盖迁移

先把原有宽窄窗口用例改为验证主滚动。修改前，1100 与 390 宽度均失败：从待办卡片发起上滑后，首页滚动位置不变。日志位于本机 `<private-evidence>/legacy-tmp/ubaa-home-layout-red.log`。

实现后用 600 高度确保宽屏也有可滚动内容；新布局在原 1000 高度已能完整容纳预览与功能入口，不能再把没有滚动空间误判为手势失败。两种宽度现验证：滚动预览带动首页、仅预览前四项、展开后末尾任务可点击、收起恢复预览、待办区域下拉触发一次首页刷新。

原“待办独立滚动且不移动今日课表”的两项旧断言被上述新交互覆盖替代；末尾任务可达、原目标导航、最近访问排序继续覆盖。原生与应用测试共用的首页滚动辅助函数同步改为主滚动及按需展开，七来源直达详情与签到取消保护保留。

## 验证

共享 UI 聚焦 29 项通过，包含首页窗口、缓存、投影、最近访问、导航与大字可访问性。应用首页 4 项直达与签到取消回归通过。`just check-changed` 通过完整 Rust/Shell 门禁、七包 1433 项 Flutter 测试、格式与静态分析、引用／布局／敏感／模块检查以及 FRB 生成零漂移。

macOS 与 iPhone 17 Pro 模拟器各 16 个原生合成场景通过（各另含框架 teardown），覆盖明暗主题、长内容与 1.3 字号、空／失败／加载、42 项展开及原操作。macOS 截图核对后将查看全部按钮对齐右侧；最终样式再通过 iPhone 套件与首页窗口专项复验。已目视核对待办预览、来源图标与手机双列磁贴、大字单列，两个平台各保存 56 张 PNG。模拟器恢复运行前的关闭状态。
