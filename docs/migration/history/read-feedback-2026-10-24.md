# 加载过程不显示失败与保存时间

## 原因与修改

首页将所有 stale 来源计入失败列表，而 stale 同时承载本地内容恢复、部分内容和真实刷新失败；通用详情在 stale 没有错误且没有 evidence 时也生成默认失败提示，成绩页则直接把 stale 显示为刷新失败。这些判断使尚未报错的内容显示失败和重试。

首页现在只有明确 failure，或 stale 且有实际错误时，才列入失败来源。通用详情、成绩和独立预约页面依据实际错误显示提示，正在加载时不呈现上一轮错误或不完整说明。阳光记录及活动类型刷新期间不显示上一轮失败。当前教学周尚未确定或返回空结果不再被当作失败来源。

资料、通用详情、成绩统计、图书馆、研讨室、活动类型、阳光概要和记录去掉保存/更新时间及旧数据来源说明。课表既有静默同步继续保持。有内容的刷新保留内容；不完整空快照的读取中使用动画，不用“暂无数据”或失败文字替代正在进行的读取。

实际错误继续保留原因和重试；最终不完整结果的统计完整度、预约写入资格、账号边界、写入未知结果核对及真实业务日期保持原有语义。本轮只修改展示，未改变学校请求、缓存 evidence、认证及持久化数据，也未触发真实学校专项验收。

## 回归与覆盖调整

新增通用详情状态转换反例：已有内容在 stale 无错误时误出现重试；修改前 RED，修改后经历待更新、加载、真实错误、再次加载和成功时，只在真实错误阶段出现错误与重试，课程内容持续可见。首页另覆盖本地待办恢复不误报失败，补充来源真正失败时保留待办并出现重试。

旧保存时间与来源文案断言删除后，保留以下行为覆盖：资料遮罩和联系人保护、在线资料更新不退出当前页；成绩渐进读取时统计数字可用；考试内容保持；评教和图书馆缓存不授予写资格；活动类型选项和不完整状态；阳光部分空页不冒称无记录；课表真实失败后仍保留课程、周次和日期。首页一个仅检查保存时间的用例被新增恢复/失败转换用例覆盖，未削减数据或操作断言。导航连续性夹具补入真实网络错误，继续验证重试使用已应用查询而非未应用草稿。

按实际 UI 展示影响运行共享 UI、宿主与官方应用三包检查，以及引用、布局、模块和敏感检查。`just check-plan` 因原有未跟踪 `.serena/` 保守建议全量，该目录保持原样；本轮没有改动 Rust、生成绑定或平台存储。

## 验证结果

共享 UI 371、共享宿主 101、官方应用 79 项测试，共 551 项通过，三包格式及静态分析通过。引用、布局、模块和敏感扫描通过。macOS 正式 Debug 已重建并使用独立检查配置重新打开；本轮未新增原生截图或真实账号专项验证。
