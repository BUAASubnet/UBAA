# 功能页宽度统一与空教室夜间配色

## 发现与修改

空教室页在主框架中单独使用 1600 逻辑像素最大宽度，其他功能为 1040；空教室内部边距固定为 16，又与功能列表宽屏时的 32 不同。删除宽度例外，主框架统一使用主题中的 1040 最大宽度；页面左右边距统一复用原有手机 16、中等窗口 24、宽屏 32 的规则。

| 页面 | 检查结果与处理 |
| --- | --- |
| 首页、功能列表、设置、成绩、考试、作业、博雅统计、周课表正文 | 已使用共享页面边距和内容宽度，保持原布局。 |
| 空教室 | 校区、日期、搜索、楼栋与表格统一左右边距，表格可视宽度按实际边距计算，移除 1600 宽度例外。 |
| 图书馆、研讨室、阳光打卡 | 修正正文与行内选择控件的固定 16 边距。 |
| 签到、评教、通用结果列表、业务概要 | 修正列表、概要、批量操作与分页条的固定 16 边距。 |
| 周课表切换条 | 与课表正文共享左右边距。 |
| 关于页 | 取消额外的 840 宽度限制，卡片与其他功能页对齐。 |
| 登录、详情弹窗、写入表单、错误卡片 | 独立窗口或局部内容的阅读宽度保持，不视作正常功能页的宽度例外。 |

空闲格子原来在两个主题下都使用亮绿色 `#98FB98`。改为夜间柔和深绿 `#4D735F`、浅色低饱和浅绿 `#D5E8D8`，图例与格子共用同一颜色。按用户补充要求删除格子 Tooltip，保留空闲图例、屏幕阅读器节次状态和教室名称的详情点击。

本轮只调整展示布局、主题颜色及悬停展示。楼栋分组、14 节令牌解释、日期校区查询、筛选草稿、横向滚动与固定名称列的业务行为保持。冻结目录及真实学校协议未修改。

## 回归证据与覆盖迁移

先增加宽屏教室行与返回后的功能入口左右边界比较，修改前失败，修改后通过。复用空教室 20 项查询、日期/校区切换、大字横滚、42 行连续滚动和详情测试。原 Tooltip 隐藏页清理用例随格子悬停功能移除；完整节次 `3` / `13` / `2` 的状态验证改为无障碍语义，原始字段和详情操作覆盖保留。

原生合成回归同步既有桌面行内搜索、手机全局底栏和失败后保留教室内容的实际交互，不继续断言已删除的旧数据来源文案。macOS 使用原生 Flutter 渲染图检查明暗主题，图片和日志位于仓库外私有目录。
