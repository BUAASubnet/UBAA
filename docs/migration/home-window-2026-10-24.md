# 首页待办滚动窗口与最近访问入口

## 用户要求与实现

待办仍位于今日课表下方，宽屏两列、手机和大字单列。卡片放入带边框及滚动条的独立区域，正常字体最大高度 328 逻辑像素，约容纳两行；大字时按文字缩放增加高度。少量任务按内容收缩，长标题自然换行，更多任务在区域内纵向滚动。页面外层仍可滚动到常用功能和校园生活。

常用功能最多显示四项，按实际入口访问倒序排列，重复访问移到首位；无历史时沿用原四个默认入口。功能列表、首页快捷入口、待办直达、成绩更新与写入结果入口共用访问记录。后台刷新不计入访问。

记录只保存功能标识，不包含查询参数、课程标题、账号明文或访问时间。共享宿主沿用 AccountPreferences 与现有平台偏好插件：配置目录与账号独立，串行保存；新宿主恢复原顺序，注销清除本机数据时同步清理当前账号各别名。异步恢复与本轮点击合并，以本轮访问为先；旧账号或旧学校标识的迟到恢复不交付。读取或保存失败不阻断导航，本轮排序仍可用。普通退出保留偏好。

本轮仅改变 UI 布局、入口历史和本地普通偏好接线，学校协议、请求参数、任务排序与提交行为保持原样，不触发认证/读取协议的双来源变更。

## 回归证据

实现前的三个反例失败：两种宽度下滚动待办会带动整个首页；访问考试后常用功能仍没有考试入口。实现后验证独立滚动、末尾任务点击、最近访问去重置顶、异步恢复合并、账号切换及保存失败后导航。存储覆盖跨实例恢复、配置与账号隔离、连续保存与清除顺序、输入冻结、移除入口兼容及损坏记录的明确清除。宿主原清除用例新增访问记录断言，继续检查其他账号和迟到回调拒绝。

`just check-plan` 按本轮平台偏好与 UI/宿主影响选择完整确定性门禁。本轮执行日志与运行媒体保存于仓库外私有目录，`.serena/` 和本地预览保持不提交。

原有首页六来源导航用例改为先展示待办窗口，再滚动内层列表定位任务；外层回顶部单独操作。保留六来源、今日课程排序、作业目标与返回层级、签到准备/取消、阳光提醒关闭和零提交断言，没有删除原业务覆盖。独立滚动手势及末尾点击继续由桌面和手机窗口用例验证。
