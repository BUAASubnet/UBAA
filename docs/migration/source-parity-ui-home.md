## 实施后核对

上述六来源已经实现，Domain过滤/排序6项、controller完整85项、存储2项、首页与研讨室宿主9项聚焦通过。所有网络调用复用现有UbaaBackend/FeatureQueryBackend，只补原bykcChosen、page0/size20订单、当前学期→周次三查询；当前页查询保持隔离。真实账号生产读取两路线均通过；当期已选0，明确不演示真实博雅待办点击。真实写入0。

补充生命周期修复：默认请求虽被领域查询更新当前代次，仍可按自己主页修订完成；但账号/路线生命周期失效照常丢弃。阳光固定回读开始时以其修订使旧主页默认请求失效，只在原检查接受概览后同步主页，不新发阳光Auto。新增本地UI偏好只含enabled及已观察到达标的周/学期键；损坏明确失败不覆盖、并发保存串行，不会假称学校提交成功。
