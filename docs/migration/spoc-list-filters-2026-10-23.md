# SPOC 列表筛选与展示对齐

基线 `0a550f58`。冻结旧版 `1f4b8f8412272b6a423d4ad92b396e3db721e6f3`，buaa-api `a63712fa2ae0a6c8066197063ddee98e3a6b5b81`；实施前 `just refs` 通过。

## 来源与范围

旧版 `SpocViewModel.kt`、`SpocAssignmentsScreen.kt`、`MainAppScreen.kt` 和 `SpocViewModelTest.kt` 明确：默认隐藏已截止、显示全部提交状态、截止时间升序；可以按开始时间排序、反向排序；课程名和标题忽略大小写搜索。仅未提交严格匹配 UNSUBMITTED，与显示已截止独立组合。截止时间严格早于当前时间才过期；无效日期不算过期；未知时间升序末尾、降序开头，同时间按课程名和标题排序。按课程连续展示，摘要包括状态、教师、开始/截止与分值。

旧版 `api/feature/SpocApi.kt` 与 `LocalSpocApi.kt` 提供当前学期完整摘要，显示条件不传接口。buaa-api `api/spoc/{opt,data}.rs` 提供按课程查询及 Homework/详情数据，没有 UI 筛选状态，不用其请求替代当前冻结本地实现。现有 Bridge `features/spoc/reader.dart` 读取完整摘要，UI可直接本地过滤。

本阶段只修改 UI：复用希冀的日期、排序及 Material 3 控件，显式保留两功能的默认状态和开关联动差异；删除 SPOC 手输编号查询面板与通用20项分页。列表卡片继续使用typed单项导航，保留详情、父页状态和学期概览。

协议逐列沿用 [SPOC 来源矩阵](source-parity-code-organization.md#spoc) 及其链接的认证、列表、详情逐操作记录：CAS/bootstrap/service、重定向/final URL、Cookie/token作用域、方法及精确参数、Header/编码、加密常量、DTO/解析、缓存/并发、错误/退出均不改变。不新增历史范围请求，也不新增学校写入操作。
