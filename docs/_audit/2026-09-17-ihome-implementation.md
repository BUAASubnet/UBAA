# ihome 首轮接入记录

## 实现范围

本轮在当前 Kotlin Multiplatform/Compose/Ktor 架构中加入 ihome，并提供“普通功能 → iHome”入口。包含搜索、类别与回复筛选、时间排序、诉求详情、官方回复、当前轮次进度、支持/取消支持、关注/取消关注、我的发起、我的关注、已有评价和公告。

新发起诉求按要求排除。评价提交、非空附件预览尚未实现；北航当前关闭的通用功能未开放。公告仅提供纯文本详情，不宣称富文本表格与图片完整还原。完整功能边界见 [功能文档](../features/ihome.md)。

## 关键约束

- 使用上游独立的普通详情/本人详情接口，保留列表与评价包装差异。
- 搜索请求发到上游，不能只在当前 20 条记录中做本地过滤。
- 公共分页不前进或记录重复时停止追加，不伪造下一页。
- 将上游切换操作包装为目标状态操作：先读取、单次写入、再回查。超时不自动重复发送 POST；无结果时显示未确认并要求刷新。
- 账号/模式变化销毁内存 token 与状态，旧异步响应不能覆盖新页面。
- 共享 DTO 裁剪原始用户对象；登录链和原始业务响应不进入模块日志。
- Direct、WebVPN 和中转共用协议实现，但 Mock 路由测试不等于真实 WebVPN 或真实 App 验收。
