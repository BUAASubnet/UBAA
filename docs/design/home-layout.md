# 首页待办预览与功能磁贴

日期：2026-10-25。用户确认先实施待办去外框、图标并入来源标签、四项预览、常用功能网格和正式窗口标题。

## 当前行为

- 首页默认显示已有时间排序中的前四项；超过四项时提供“查看全部（数量）”，原位展开完整列表，再次点击“收起”恢复预览。
- 待办使用首页唯一的纵向滚动，不再设置独立滚动控制器、固定高度和外框。查看全部只改变展示范围，不发起新查询。
- 预览与完整列表共用同一种待办卡片。来源标签包含小图标，取消左侧独立图标，正文获得更多横向空间。
- 常用功能与校园生活采用自适应磁贴；常用入口继续使用原有最近访问排序。标准字号的宽屏最多四列，手机通常两列，大字或更窄窗口减少列数，每行高度由内容决定。
- macOS 窗口标题和显示名称为 UBAA。可执行文件路径、Bundle ID、沙盒与用户配置归属保持，便于继续使用现有签名和构建脚本。

本轮不改变来源读取、缓存、待办投影排序、跳转目标或签到准备／确认。紧迫度、课程状态、周次及同步提示仍沿用当前行为。
