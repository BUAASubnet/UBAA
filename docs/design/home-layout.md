# 首页待办预览与功能磁贴

更新：2026-11-07。首页保留四项待办预览、常用功能网格和正式窗口标题，完整待办进入日程查看。

## 当前行为

- 首页显示已有时间排序中的前四项；超过四项时提供“查看全部（数量）”，打开日程并启用待办筛选。
- 待办预览随首页纵向滚动，不设置独立滚动控制器、固定高度和外框。日程查询使用本机事项和学校缓存。
- 首页预览使用待办卡片。来源标签包含小图标，取消左侧独立图标，正文获得更多横向空间。
- 常用功能与校园生活采用自适应磁贴；常用入口继续使用原有最近访问排序。标准字号的宽屏最多四列，手机通常两列，大字或更窄窗口减少列数，每行高度由内容决定。
- macOS 窗口标题和显示名称为 UBAA。可执行文件路径、Bundle ID、沙盒与用户配置归属保持，便于继续使用现有签名和构建脚本。

来源读取、缓存、待办投影排序与签到准备／确认沿用既有行为。首页和日程的学校事项均通过既有导航打开原功能详情，返回后保留当前入口。

## 加载与刷新

App 层持有首页各来源、当前展示日期课表和待办投影，界面只消费 `HomeState`。本机账号确认后，课表、博雅已选、研讨室订单等缓存独立恢复，教学周从缓存日期范围确定。本机首屏先取得保存的路线策略，周次、实际展示日期的课表与待办投影共用原有 800 毫秒预读预算。今日无课或课程结束时，明日课表先由完整本机学期、教学周和周课表投影；有课程和明确无课都先显示缓存，再后台更新。待办复用 Core 本地投影，不另存派生列表。地点偏好异步补入，首页不等待普通偏好读取。

主来源的首批结果、补充来源与可见的今日／明日课表均取得本轮结果后，结束主刷新指示。作业详情可以继续后台补全。单来源重试只更新该来源，不使其他来源和成绩检查失效。成绩检查在首页可见内容就绪后以后台优先级启动。

刷新和暂时失败保留同账号、同查询已有内容，完整成功的空集合替换旧内容。首次读取的加载、失败与成功为空分别显示。账号或路线变化及时撤销旧内容和操作资格，内部读取计划被取代不作为业务失败提示。
