## 页面规则

1. 每页只保留一个标题和一个返回入口。手机进入领域内容后隐藏全局底栏；平板与桌面保留用于跨功能切换的侧栏，内容页不再放重复返回按钮。
2. 根据用户进一步明确的想法，搜索、筛选、查询统一收纳到顶栏右上角的一个入口。手机打开底部面板，平板/桌面打开侧面板；搜索仅本地过滤，条件更改后显式应用才读取。手填ID、多字段兼容查询继续完整可达，关闭面板保留草稿、搜索、选择与列表位置；未使用时不占正文空间。
3. 根据用户进一步明确的想法，直连/WebVPN仅使用顶栏一个路线图标；图标与tooltip表示当前显示页面的实际路线，点击显示路线说明及切换选项。未知时显示未确定，不把默认策略或已认证路线冒充本次实际路线；用户设置和诊断中的完整信息仍保留。
4. 状态卡、进度、筛选属于内容滚动的一部分，不能与固定批量栏/分页一起把列表压成窄缝。手机评教按旧版紧凑课程行展示，批量动作仅在有选择时出现；每个可写操作仍进入同一个确认状态机。
5. 列表只展示决定当前任务的字段，其余字段在本地详情中可达。SPOC/希冀的课程归属、原始截止/提交状态/成绩仍保留；typed父子导航、二元键和有序批量查询不改。
6. 手机维持单列，功能网格至少两列；平板按实际宽度增加网格列数，内容可采用列表/详情并列；桌面加宽导航与内容上限，鼠标/键盘、长文和滚动可用。主要布局遵循旧版列表结构，不为宽屏把每页都改成大表格。
7. 新布局不恢复旧版未经当前合同允许的行为：真实学校写入仍禁止，确认/未知结果/未尝试/固定路线回读保留；联系人默认遮罩，图书馆日期与时段未证明的关联不自动绑定；旧版已存在但当前公开合同未接入的能力继续单独列明。
