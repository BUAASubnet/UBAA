# 应用配色：中性表面与蓝色强调

更新：2026-10-25。适用于共享 Flutter UI 的浅色和深色主题。

## 依据与取舍

用户反馈首页蓝紫色背景、标签、图标和日期同时强调，画面突兀。本轮采用 Microsoft Fluent 2 的中性色层次、克制使用品牌色、按用途区分状态色的原则；通过现有 Material 3 ColorScheme 统一实现，控件和交互结构保持。

官方资料（2026-10-25 查阅）：

- [Fluent 2 Color](https://fluent2.microsoft.design/color)：表面、文字和布局以中性色为基础；品牌色用于操作和选中状态，避免铺满大面积背景；语义色用于反馈并配合其他提示。
- [Fluent 2 Color Tokens](https://fluent2.microsoft.design/color-tokens/)：按背景、前景、品牌和状态定义角色，浅深主题分别映射。
- [Android 官方配色指南](https://developer.android.com/design/ui/mobile/guides/styles/color)：使用颜色角色，成对设置容器与前景，提供明暗方案，避免装饰颜色过多。
- [W3C 文字对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)：普通文字至少 4.5:1。

具体色值是本项目的选择，不表示复刻某一产品或取得设计系统认证。

## 颜色角色

实现入口：`packages/ubaa_ui/lib/src/theme.dart`。页面使用 ColorScheme 角色，避免局部写死色值。

| 用途 | 浅色 | 深色 | 使用边界 |
|---|---|---|---|
| 页面底色 | `#F7F7F7` | `#1B1B1B` | 正文与顶栏 |
| 卡片 | `#FFFFFF` | `#252525` | 承载正文的独立表面 |
| 导航与普通标签底色 | `#F0F0F0` | `#202020` | 中性层次，不暗示可点击或已选中 |
| 主要文字 | `#242424` | `#F0F0F0` | 标题、正文和待办时间 |
| 次要文字与图标 | `#616161` | `#BDBDBD` | 课程地点、来源和普通状态标签 |
| 强调色 | `#0F6CBD` | `#77B7F7` | 主操作、链接和功能入口图标 |
| 选中背景／前景 | `#E5F0FA`／`#0F548C` | `#173B57`／`#B4D6FA` | 导航、筛选和选中项 |
| 装饰边界 | `#E0E0E0` | `#404040` | 卡片分隔；不作为操作唯一标识 |
| 控件轮廓 | `#757575` | `#8A8A8A` | 输入和描边控件 |

首页来源、普通待办状态和课程简称采用中性标签；待办标题与日期使用主要文字，课程说明和图标使用次要文字。常用功能入口保留蓝色图标，中性底座降低大面积色块。错误继续采用既有错误角色；课程区别色和空教室空闲绿色继续表达原有含义。

## 验证

本轮只调整样式，复用现有覆盖，不新增固定色值或文案缺席测试。37 项聚焦测试通过，覆盖导航断点、大字、首页和课表颜色；六张既有 golden 经前后对照仅有配色变化，布局保持。

从当前主题声明提取颜色，计算两主题各 18 组前景／背景对比：包含正文和次要文字在全部六种表面上的组合、按钮、选中项、反色提示以及功能图标底座。浅色最低 4.72:1，深色最低 6.24:1，均超过普通文字 4.5:1 阈值。该计算限定这些颜色组合，不能代替完整无障碍审计。

macOS 原生合成首页套件的 16 个场景通过（另含框架 teardown），覆盖两主题的正常、空、部分失败、旧数据、加载、长内容、多待办和混合路线。已目视核对正常首页、待办、确认页与大字页面；56 张 PNG 保存到仓库外私有目录。移动端复用现有窄屏与大字 Widget/golden 覆盖，本轮未重新运行移动设备。

运行命令：在 `packages/ubaa_ui` 执行聚焦 `flutter test ... --update-goldens`；在 `apps/ubaa_flutter` 执行 `flutter drive --driver=test_driver/ui_render.dart --target=integration_test/synthetic/home/flow_test.dart -d macos`。原生命令清除真实账号环境变量，使用合成后端；`UBAA_UI_EVIDENCE_DIR` 指向仓库外的 `UBAA-private-evidence/color-20261025-macos` 私有目录。

`just check-changed` 通过：UI 429、宿主 101、官方应用 78 项，共 608 项测试通过；格式、静态分析、冻结引用、敏感扫描、布局与模块检查通过。正式 macOS Debug 构建及产物签名／权限检查通过，已使用独立检查配置重新启动；实际核对紧凑侧栏和展开侧栏的首页，应用停留在宽屏首页。
