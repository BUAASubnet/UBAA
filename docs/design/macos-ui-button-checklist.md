# macOS 逐按钮验收清单

本表是现有84项功能编号下的操作检查点，不新增功能编号。以当前共享组件和冻结旧版逐项对照；每一项必须记录适用的生产只读或明确合成backend的实际computer use操作。当前全部仍待最终候选验收，前阶段的真实局部结果见[实测记录](macos-ui-button-results.md)。

写入行仅在明确合成backend操作确认提交，真实学校写入为0。共享读取控件必须在每个适用领域分别执行；六状态、三校区、地图变换等同形控件仍逐一点击并记录，不能把一个代表动作当全部通过。不可达的数据/资格分支保留原因并用同一生产组件合成补验。
