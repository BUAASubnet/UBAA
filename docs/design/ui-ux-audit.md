# 现有 UI/UX 审查与问题记录

日期：2026-09-08。基线源码 `e6e0e3c5`，仅巡检测试接线有增量。用户群体为大学生；高频任务假设来自合同与功能结构，没有进行用户访谈，不宣称用户研究结论。

## 已实际观察的优点

macOS 800×600 内容窗口、深色、显式合成 backend：登录表单居中且有密码显示切换、记住密码/自动登录与路线入口；统一 Material 3 和蓝紫主色有辨识度。首页文字/图标/状态共同表达，卡片有明确实际路线。课表、考试、成绩和博雅页面保留查询、白名单字段与返回；博雅长详情可滚动至操作按钮，选课确认确实单独显示目标、实际路线、有效期与警告。没有为了视觉省略确认步骤。

## 任务点击基线

从首页：课表/考试/成绩/博雅入口各1次点击；进入课堂签到/场馆/阳光/评教需高级分组+卡片共2次。课程/订单详情再选查询视图、选或输入ID、应用，至少另3次操作；图书馆多层手输参数会增加操作。前四项入口已实际打开，其余点击数为静态下界。截图目录 `evidence/ui-ux/` 中 `p0-*-macos-dark.png` 为实际 App 合成渲染，不是原型或上游证据。

## 审查进度

已实际观察：登录、主页及十二领域主页；博雅列表/滚动/确认/取消；阳光表单和缺项错误；我的/诊断/清除确认/取消。iPhone 7项宿主fake集成复验通过，涵盖十二入口、typed查询、十种写操作。其余主要子视图的逐页视觉、手机/平板最终布局仍待完成，不将该有限基线称为全页面验收。P0/P1 严重问题尚未清零。
