# P5-E 系统选图实操补验（2026-09-12）

本轮使用 `ui_photos/inspection.dart` 启动真实 macOS App，系统能力由生产 `createDefaultPlatformCapabilities` 创建，学校业务固定为 `SportsWriteBackend(success)` 内存实现。没有读取真实照片、上传、prepare 或学校写入。

真实 CUA 操作依次验证：选择蓝色合成 PNG → 系统 Cancel 保留蓝图 → 重选橙图并更新预览/元信息 → 选择 12,589,062 字节合成 PNG 被拒绝且保留橙图 → 清除照片。五张未经缩放修改的原生窗口截图均已查看，无个人资料或原始业务响应。结果与 SHA 见 `results.json`；源码逐文件 SHA 与上层 `source-files.json` 完全一致。蓝图116字节，橙图137字节，实际MIME均image/png。

系统窗口开始展示用户默认Documents目录，只观察后立即前往任务合成目录，不归档系统文件列表。初次剪贴板输入超时，重新读取系统GoToWindow后使用AX setValue输入已知合成路径；文件列点击未选中，改用系统前往完整文件并点“选择”。未通过文件系统绕过系统授权，也未将临时路径传入Flutter。

本轮 macOS 正文坐标点击与滚动生效，不能继续沿用此前“正文无法操作”的结论；AX仍只暴露Flutter容器，正文位置依据当前截图。iPhone17安装启动同inspection入口后，CUA在点击阳光入口时返回“Mac is locked”，因此手机与平板系统选图仍未验收。模拟器仅加入三张合成测试PNG，旧App设备未修改。既有探测/表单r3结果不改写为系统选图成功。

边界：本轮仅macOS浅色系统选图局部验收，未验证深色系统选择、失败后成功重试、带原图退出再进入；清除后原失败提示仍保留。Android旧拍照、Windows/Linux照片、OHOS设备、P4余项、P5全领域及P6/P7继续。
