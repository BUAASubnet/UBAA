# UI 验收证据存储

本文供需要采集或查阅 UI 截图、录屏等运行证据的开发者使用，说明新证据的存放位置、历史归档的查找方式和本机标识的脱敏写法。

## 新证据的存放

- 运行截图、录屏和逐图元数据统一保存在被忽略的 `.ubaa_local/` 任务子目录。这一要求由用户于 2026-10-30 更新。
- 采集前，将已有驱动使用的 `UBAA_UI_EVIDENCE_DIR` 设为 `.ubaa_local/` 下本次运行的私有绝对目录。
- 审阅后只把脱敏文字摘要同步到本目录。图片、录屏、逐图元数据、清单和哈希留在 `UBAA_UI_EVIDENCE_DIR`。
- `.gitignore` 忽略整个 `.ubaa_local/`，并对本目录常见媒体扩展名提供额外保护，不得用强制暂存绕过。
- 本目录版本化原型源文件、脱敏文字说明和历史归档索引。应用图标、业务静态地图与 golden 测试基准作为工程资源，在各自工程目录管理。使用纯合成数据制作并审核的商店宣传图是发布素材，存放在 [网站宣传资源目录](../../site/public/screenshots/)，生成方式见[发布手册](../../runbooks/flutter-release.md#生成商店宣传图)。

## 历史归档

历史材料按[批次索引](batches.md)定位。2026-10-30 起，3967 个逐图 JSON 元数据和 40 份 SHA256SUMS 移出当前文件树，原文完整保存在提交 `7348b8b3` 及更早的 Git 历史中，恢复方法见批次索引。移出理由见[决策记录](../../protocol/decision-log.md)。

外部截图归档标识为 `UBAA-ui-ux-20260914`，保存 3,981 张截图，合计 1,397,627,832 字节；连同配套文字和元数据共 8,001 个文件逐文件校验一致。仓库内的[归档索引](ui-ux/external-archive.json)记录原源码终点、清理后终点和外部清单摘要，不包含截图字节或本机私有路径。

历史提交中的逐图元数据（`image`、`pngSaved`、`savedScreenshots`、相对 PNG 路径及 `SHA256SUMS`）描述原采集结果：

- 相对路径是外部归档的逻辑路径，不能据此认定图片本体仍受 Git 跟踪。查看原图时在归档根目录下按同一路径定位。
- `source-files.json` 的源码内容摘要保持有效，`systemCameraVerified=false` 等验收分类不变。

归档另含原未发布提交的 Git bundle 与迁移校验记录，可用于恢复历史材料。当时只清理了已发布基点之后的 40 个本地提交，旧 SHA 与新 SHA 的关系见[提交映射](../../archive/evidence/2026-09-14-ui-ux-commit-map.txt)；映射中不变的 SHA 表示该提交原本没有截图差异。

截图归档只保留原有证据类别，不扩大设备操作、真实读取或业务写入的通过范围，也不构成当前授权。当前阶段目标见 [goal.md](../../project/goal.md)，实际结果见[状态页](../../project/status.md)。

## 路径与本机标识

`UBAA_UI_EVIDENCE_DIR` 指向 `.ubaa_local/` 中的任务子目录，例如 `<repo-root>/.ubaa_local/ui_evidence/<run-id>/`。工具配置和调用遵守 [AGENTS 工具链规则](../../../AGENTS.md#项目工具链入口)。`ui_render.dart` 在任何写入前解析实际路径（包括尚未创建目录的现有父目录与符号链接），只允许写入实际位于 `.ubaa_local/` 下的任务子目录。

受跟踪的说明只记录 `.ubaa_local/<任务>/<批次>/<文件名>`、内容摘要、采集方式与实际验收结论，不写个人家目录绝对路径。

- `<repo-root>` 表示本仓库根目录，`<simulator-id>` 表示本轮设备标识，均不是可直接执行的路径。
- 私有材料标识使用纯文本，不生成指向个人文件系统的 Markdown 链接。

历史记录中的个人路径已改为逻辑占位：

- `<private-evidence>/legacy-tmp/` 表示原临时目录记录，只保留文件名及其历史上下文，不表示文件已迁移或仍可读取。需要保留的证据应直接写入持久的私有目录。
- 历史 SDK 位置改为项目入口或环境变量，旧工作树位置保留为 `<private-evidence>/source-checkouts/UBAA`，原来源提交与例外性质不变。
- 历史模拟器 UUID 改为 `<simulator-id>`，其他设备描述和验收分类保留。

既有 SHA256SUMS 描述采集时的原始材料。元数据经过路径脱敏后可能与原始摘要不同，这些摘要不能当作当前元数据文件的校验结果。新归档应为脱敏后的元数据重新生成摘要，并另存原始材料摘要。

历史 E3c 的 `capture-macos.py` 通过 `--checkpoint-dir`、`--evidence-dir`、`--window-id` 接收输入，使用 macOS 系统 `screencapture`，不依赖个人截图技能目录。保留该脚本不增加任何原生验收结论。
