## 路径与本机标识

新证据统一使用 `UBAA_UI_EVIDENCE_DIR` 指定 `.ubaa_local/` 中的任务子目录，例如 `<repo-root>/.ubaa_local/ui_evidence/<run-id>/`。工具配置和调用遵守 [AGENTS 工具链规则](../../../AGENTS.md#项目工具链入口)。`ui_render.dart` 在任何写入前解析实际路径，包括尚未创建目录的现有父目录与符号链接，只允许写入实际位于 `.ubaa_local/` 下的任务子目录。

受跟踪说明只记录 `.ubaa_local/<任务>/<批次>/<文件名>`、内容摘要、采集方式与实际验收结论，不写个人家目录绝对路径。`<repo-root>` 表示本仓库根目录，`<simulator-id>` 表示本轮设备标识，均不是可直接执行的路径。私有材料标识使用纯文本，不生成指向个人文件系统的 Markdown 链接。

阶段 1 将历史个人目录和临时日志路径改为逻辑占位。`<private-evidence>/legacy-tmp/` 表示原临时目录记录，仅用于保留文件名及其历史上下文，不表示文件已迁移或仍然可读取。未来需要保留的证据应直接写入持久的私有目录。历史 SDK 位置改为项目入口或环境变量，旧工作树位置保留为 `<private-evidence>/source-checkouts/UBAA`，原来源提交与例外性质不变。

历史模拟器 UUID 改为 `<simulator-id>`。元数据中的其他设备描述和验收分类保留；既有 SHA256SUMS 描述采集时的原始材料，元数据经过路径脱敏后可能与原始摘要不同，不能将这些摘要视为当前元数据文件的校验结果。新归档应为脱敏后的元数据重新生成摘要，并另存原始材料摘要。

移出逐图元数据的理由见[决策记录](../../migration/decision-log.md)。新批次只提交文字摘要，逐图元数据、清单和哈希与截图一起留在 `UBAA_UI_EVIDENCE_DIR`。历史 E3c 的 `capture-macos.py` 通过 `--checkpoint-dir`、`--evidence-dir`、`--window-id` 接收本轮输入，使用 macOS 系统 `screencapture`，不依赖个人截图技能目录。脚本保留不增加任何本轮原生验收结论。
